Precisa de ajuda?
Quais fotos e vídeos posso importar?

SD Card Import reconhece formatos RAW, JPEG e de vídeo comuns. A análise também mostra arquivos auxiliares de metadados da câmera e arquivos incompatíveis para você conferir o cartão. Veja o guia para o fluxo completo.

O que acontece se eu importar o mesmo cartão de novo?

SD Card Import reconhece os arquivos registrados no histórico e evita copiá-los novamente. A revisão mostra o que é novo e o que já foi importado antes de começar.

Para onde vão meus arquivos?

Para as pastas de destino escolhidas. Você pode manter fotos e vídeos juntos, usar destinos separados e organizar por data de captura. Confira os caminhos planejados antes de copiar.

SD Card Import apaga algo do meu cartão?

SD Card Import copia suas mídias sem apagar automaticamente os originais do cartão. Ao terminar, você pode ejetar com segurança um cartão removível compatível.

Qual é a diferença entre as edições?

O download direto aqui é gratuito e de código aberto sob a licença MIT. Você pode baixar o app assinado ou explorar o código no GitHub. SD Card Import, a edição da App Store, inclui uma importação concluída grátis e depois uma compra única de US$ 9,99 nos EUA para importações ilimitadas com Compartilhamento Familiar. A análise e a prévia continuam gratuitas.

O que preciso para começar?

Um Mac com macOS 14 ou posterior, um cartão montado ou pasta de origem e espaço suficiente no destino. Instale SD Card Import pela App Store e escolha suas pastas. O guia de instalação cobre as duas edições.
