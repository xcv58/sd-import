Mantenha seu app atualizado.

SD Card Import recebe atualizações pela App Store. Abra a App Store e confira Atualizações.

As instruções e downloads abaixo são do SD Import, a edição direta que usa Sparkle e GitHub Releases. Obter a edição da App Store.

Verificar manualmente

  1. Abra SD Import em Aplicativos.
  2. Escolha SD Import > Buscar atualizações….
  3. Se o Sparkle não mostrar atualizações, o app está atualizado no canal público.

Verificar no GitHub

Compare a versão instalada com a mais recente no GitHub. As versões públicas incluem SD-Import.dmg, SD-Import.zip, appcast.xml e notas da versão.

Versão mais recente no GitHub

Se uma atualização parecer errada.

Use primeiro a versão pública mais recente e compartilhe o diagnóstico se as importações ainda não funcionarem como esperado.

Verifique atualizações novamente, compare sua versão com a mais recente no GitHub, reinstale o DMG mais recente se necessário e contate o suporte com o resumo da prévia e o diagnóstico exportado.
