L’assistance commence par l’aperçu.

Assistance pour SD Import (édition directe) et SD Card Import (édition App Store). La version de l’application, celle de macOS, l’état de la destination et le résumé de la tâche facilitent le diagnostic des problèmes d’import.

Contact

Assistance par e-mail : i@xcv58.com

Bugs publics et demandes de fonctionnalités : GitHub Issues

Signalements de sécurité : suivez SECURITY.md et ne créez pas de ticket public pour une vulnérabilité présumée.

Contacter l’assistance par e-mail Créer un ticket public

Informations à inclure

  • Nom, version et numéro de build de l’application : SD Import ou SD Card Import.
  • Version de macOS et modèle de Mac.
  • Marque de l’appareil ou de la carte, système de fichiers et type de lecteur.
  • Démarrage automatique ou manuel de l’import.
  • Contenu de l’aperçu et résultat après l’import.

Exporter les diagnostics.

L’export des diagnostics est volontaire et expurgé. Il exclut les médias, les noms de fichiers et les chemins source et de destination complets.

1

Ouvrir Diagnostics

Dans les deux éditions, choisissez Diagnostics dans la barre latérale.

2

Exporter

Choisissez Copier les diagnostics ou Exporter les diagnostics. Vérifiez le fichier avant de le partager.

3

Choisir les pièces jointes

Ne partagez que le nécessaire. Ne joignez ni médias privés, ni copies intégrales de cartes, ni identifiants secrets.

Rapports de plantage.

Aucune édition n’envoie automatiquement de rapports de plantage. macOS peut enregistrer un rapport local que vous pouvez choisir de partager.

~/Library/Logs/DiagnosticReports/

Dans l’édition directe, utilisez Diagnostics, Afficher les rapports de plantage ou Exporter le dernier rapport. L’édition App Store ne peut pas parcourir les rapports système ; utilisez Console dans macOS si l’assistance en demande un. Vérifiez-le avant de le partager.

Achats et restauration de l’accès

SD Card Import offre un import terminé gratuit. L’achat SD Import Unlimited débloque les imports terminés illimités avec le Partage familial. L’analyse et l’aperçu restent gratuits. SD Import, l’édition directe, est gratuit et sans achat intégré.

Dans SD Card Import, ouvrez Réglages > Achat et choisissez Restaurer les achats. Utilisez le compte Apple ayant effectué l’achat ou un compte éligible au Partage familial. Si l’accès manque toujours, contactez l’assistance avec la version de l’application et le contenu de la fenêtre d’achat.

Rouvrir une fenêtre fermée

Dans SD Card Import, choisissez Fenêtre > Afficher SD Card Import, Fichier > Importer depuis une carte (Commande-I), ou cliquez sur l’icône dans le Dock.
