Choisissez votre édition.

Obtenez SD Card Import sur le Mac App Store ou choisissez SD Import, l’édition directe gratuite pour Mac avec puce Apple.

SD Card Import · Mac App Store

SD Card Import prend en charge les Mac avec puce Apple ou Intel sous macOS 14 ou ultérieur. Téléchargez-le sur le Mac App Store.

Un import terminé avec succès est gratuit. Ensuite, un achat unique de 9,99 $ US débloque les imports terminés illimités et le Partage familial. L’analyse et l’aperçu restent gratuits. Les prix locaux peuvent varier. Sans abonnement.

Installez SD Card Import via l’App Store, puis choisissez les dossiers source et de destination dans l’application. Apple gère l’installation, les mises à jour et les achats.

Voir l’édition App Store · Aide pour les achats et la restauration

SD Import · Téléchargement direct gratuit

Téléchargez le DMG, déplacez l’application dans Applications, puis choisissez vos dossiers au premier lancement.

Configuration requise : Mac avec puce Apple, macOS 14 ou ultérieur et assez d’espace libre à la destination des photos ou vidéos.

1

Télécharger

Obtenez SD-Import.dmg dans la dernière version GitHub.

2

Copier dans Applications

Ouvrez le DMG et glissez SD Import.app dans Applications.

3

Choisir les dossiers

Ouvrez l’application et choisissez les dossiers source et de destination lors de la configuration initiale.

Télécharger pour Mac avec puce Apple Voir la dernière version GitHub

Gatekeeper et premier lancement.

Si macOS indique que l’application vient d’Internet, choisissez Ouvrir. Si le lancement est bloqué, ouvrez Réglages Système, Confidentialité et sécurité, puis choisissez Ouvrir quand même pour SD Import.

Configuration requise

  • Mac avec puce Apple.
  • macOS 14 ou ultérieur.
  • Carte SD, lecteur de cartes, carte montée via un appareil photo ou dossier source choisi.
  • Assez d’espace libre à la destination des photos ou vidéos.
