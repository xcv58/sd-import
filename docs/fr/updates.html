Gardez votre application à jour.

SD Card Import reçoit ses mises à jour via l’App Store. Ouvrez l’App Store et consultez Mises à jour.

Les instructions et téléchargements ci-dessous concernent SD Import, l’édition directe utilisant Sparkle et GitHub Releases. Obtenir l’édition App Store.

Vérifier manuellement

  1. Ouvrez SD Import depuis Applications.
  2. Choisissez SD Import > Rechercher des mises à jour….
  3. Si Sparkle n’indique aucune mise à jour, l’application est à jour pour le flux public.

Vérifier sur GitHub

Comparez la version installée à la dernière version GitHub. Les versions publiques comprennent SD-Import.dmg, SD-Import.zip, appcast.xml et les notes de version.

Dernière version GitHub

Si une mise à jour semble incorrecte.

Utilisez d’abord la dernière version publique, puis partagez les diagnostics si les imports ne fonctionnent toujours pas comme prévu.

Recherchez à nouveau les mises à jour, comparez votre version à la dernière version GitHub, réinstallez le dernier DMG si nécessaire, puis contactez l’assistance avec le résumé de l’aperçu et les diagnostics exportés.
