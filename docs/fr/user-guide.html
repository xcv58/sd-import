Guide d’utilisation

Réglez les destinations une fois, prévisualisez chaque carte avant la copie et gardez une trace claire des imports de SD Import.

Les captures de ce guide montrent SD Import, l’édition directe. SD Card Import est l’édition App Store ; consultez la disponibilité et les tarifs et l’aide aux achats et à la restauration.

Vous utilisez SD Card Import ? Installez-le depuis le Mac App Store, puis choisissez les dossiers source et de destination. Le parcours ci-dessous montre SD Import, l’édition directe.

Démarrage rapide.

Il suffit généralement d’installer l’application et de régler les destinations une fois, puis de vérifier l’aperçu à chaque insertion de carte.

1

Installation

Téléchargez le DMG signé, ouvrez-le et glissez SD Import.app dans Applications.

2

Régler les dossiers

Ouvrez les réglages, choisissez les destinations des photos et vidéos et activez, si souhaité, l’éjection automatique ou les reçus d’import portables. Ces reçus écrivent un registre caché .sd-import sur les sources accessibles en écriture pour éviter les doublons sur d’autres Mac.

3

Importer

Insérez une carte, vérifiez l’aperçu et laissez-la connectée jusqu’à la fin de la copie. Les fichiers reconnus dans l’historique portable portent la mention Autre Mac ; l’historique est revérifié avant la copie et Importer quand même reste actif pendant la reconstruction du plan de destination. Éjectez ensuite la source depuis le récapitulatif.

Importer depuis une carte.

SD Import peut apparaître automatiquement au montage d’une carte. Vous pouvez aussi ouvrir l’application et choisir Importer depuis une carte….

  1. 1

    Connectez une carte.

    Insérez une carte SD ou branchez un lecteur de cartes d’appareil photo.

  2. 2

    Vérifiez l’analyse.

    Identifiez les fichiers nouveaux, déjà importés, non pris en charge ou en conflit.

  3. 3

    Lancez la copie.

    Confirmez les destinations et laissez la source connectée jusqu’à la fin de l’import.

  4. 4

    Éjectez en toute sécurité.

    Choisissez Éjecter la source sur le récapitulatif ou activez l’éjection automatique dans les réglages. Celle-ci n’a lieu qu’après un import sans erreur.

Précautions

  • SD Import copie les fichiers ; il n’efface pas la carte.
  • Si les reçus portables sont activés, SD Import écrit uniquement son registre caché .sd-import sur la source. Les sources verrouillées ou en lecture seule restent utilisables avec un avertissement.
  • Les fichiers déjà importés sont ignorés ensuite. Importer quand même est réservé aux fichiers reconnus dans l’historique portable. Si un fichier source change après l’analyse, SD Import exige une nouvelle analyse au lieu d’utiliser un historique périmé.
  • Si un fichier différent existe déjà à destination, SD Import conserve les deux en ajoutant un suffixe.
  • Gardez l’application dans Applications pour permettre l’installation correcte des mises à jour.

Raccourcis clavier

  • Command-I : ouvrir Importer.
  • De Command-1 à Command-4 : Importer, Historique, Réglages, Diagnostics.
  • Control-Tab : panneau suivant.
  • Command-R : actualiser l’historique.
  • Command-, : réglages.

Si l’import ne démarre pas automatiquement.

Vérifiez que Notifier au montage d’une carte est activé dans les réglages, ouvrez SD Import manuellement, puis choisissez Importer depuis une carte…. Si le problème persiste, exportez les diagnostics et contactez l’assistance.
