Quelques questions utiles

Avant de
brancher votre carte.

Besoin d’aide ?
Quels types de photos et vidéos puis-je importer ?

SD Card Import reconnaît les formats RAW, JPEG et vidéo courants. L’analyse affiche aussi les fichiers annexes de métadonnées et les fichiers non pris en charge pour vérifier le contenu de la carte. Consultez le guide pour le parcours complet.

Que se passe-t-il si j’importe à nouveau la même carte ?

SD Card Import reconnaît les fichiers enregistrés dans son historique et évite de les recopier. L’aperçu distingue les nouveautés des fichiers déjà importés avant de commencer.

Où vont mes fichiers ?

Dans les dossiers de destination choisis. Vous pouvez réunir photos et vidéos, utiliser des destinations distinctes et classer par date de prise de vue. Vérifiez les chemins prévus avant la copie.

SD Card Import supprime-t-il quelque chose sur ma carte ?

SD Card Import copie vos médias sans supprimer automatiquement les originaux de la carte. Après l’import, vous pouvez éjecter en toute sécurité une carte amovible prise en charge.

Quelle différence entre les deux éditions ?

L’édition directe proposée ici est gratuite et open source sous licence MIT. Téléchargez l’application signée ou consultez le code sur GitHub. SD Card Import, l’édition App Store, offre un import terminé gratuit, puis un achat unique de 9,99 $ US pour des imports illimités avec le Partage familial. L’analyse et l’aperçu restent gratuits.

Que faut-il pour commencer ?

Un Mac sous macOS 14 ou ultérieur, une carte montée ou un dossier source, et assez d’espace à destination. Installez SD Card Import depuis l’App Store et choisissez vos dossiers. Le guide d’installation couvre les deux éditions.
