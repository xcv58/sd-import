一些常見問題

插卡
之前。

需要幫助？
可以匯入哪些照片和影片？

SD Card Import 識別常見的 RAW、JPEG 和影片格式。掃描也會顯示相機中繼資料附屬檔案和不支援的檔案，方便你檢查卡上的內容。完整流程請參閱指南。

再次匯入同一張卡會怎樣？

SD Card Import 識別匯入歷史中記錄的檔案並跳過重複拷貝。開始前，預覽會顯示哪些是新檔案、哪些已匯入。

檔案保存在哪裡？

保存在你選擇的目標檔案夾中。照片和影片可以放在一起，也可以使用不同的目的位置，並按拍攝日期整理。拷貝前可檢查計劃路徑。

SD Card Import 會刪除卡上的內容嗎？

SD Card Import 拷貝媒體時不會自動刪除來源卡上的原件。匯入結束後，可以安全推出受支援的可移動記憶卡。

兩個版本有什麼區別？

此處提供的直接下載版免費，並依據 MIT 授權條款開源。可以下載已簽名的App，或查看 GitHub 上的源代碼。App Store 版 SD Card Import 可免費完成一次匯入，之後一次支付 9.99 美元（美國價格）即可無限次匯入，並支援家人共享。掃描和預覽始終免費。

開始使用需要什麼？

一台運行 macOS 14 或更新版本的 Mac、已掛載的記憶卡或來源檔案夾，以及目的位置的足夠空間。從 App Store 安裝 SD Card Import 並選擇檔案夾。安裝指南涵蓋兩個版本。
