讓App保持最新。

SD Card Import 通過 App Store 接收更新。打開 App Store 並查看“更新”。

以下說明和下載適用於使用 Sparkle 與 GitHub Releases 的直接下載版 SD Import。獲取 App Store 版。

手動檢查

  1. 從“應用程式”打開 SD Import。
  2. 選擇 SD Import > 檢查更新…。
  3. 如果 Sparkle 提示沒有可用更新，則App已是公開更新源中的最新版本。

在 GitHub 上核對

將已安裝App的版本與最新 GitHub Release 比較。公開發行版包含 SD-Import.dmg、SD-Import.zip、appcast.xml 和發行說明。

最新 GitHub Release

如果更新看起來不對。

請先使用最新公開發行版；如果匯入仍不符合預期，再分享診斷。

再次檢查更新，將已安裝版本與最新 GitHub Release 比較，必要時重新安裝最新 DMG，然後聯繫支援並提供預覽摘要和診斷導出。
