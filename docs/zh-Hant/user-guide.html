使用指南

設定一次目的位置，每次拷貝前預覽記憶卡，清楚記錄 SD Card Import 已匯入的內容。

快速開始。

大多數使用者只需安裝一次、設定一次目的位置，並在每次插卡時檢查預覽。

1

安裝

通過 App Store 安裝 SD Card Import，然後在App中選擇來源檔案夾和目標檔案夾。Apple 負責安裝、更新和購買。

2

設定檔案夾

打開“設定”，選擇照片和影片目的位置，還可啟用自動推出來源裝置或便攜匯入回執。便攜回執會在可寫來源上寫入隱藏的 .sd-import 台帳，讓其他 Mac 避免重複匯入。

3

匯入

插入記憶卡，允許掃描並檢查預覽。從可攜式歷史記錄識別的檔案標示為另一台 Mac；僅在希望再次複製這些檔案時選擇仍然匯入。複製完成前保持記憶卡連接，然後安全退出。

從記憶卡匯入。

記憶卡掛載時 SD Card Import 可自動出現，也可以打開App並選擇 從記憶卡匯入…。

  1. 1

    連接記憶卡。

    插入 SD 卡或連接相機讀卡器。

  2. 2

    檢查掃描結果。

    檢查新增、已匯入、不支援或存在衝突的檔案。

  3. 3

    開始拷貝。

    確認目的位置，保持來源裝置連接直到匯入完成。

  4. 4

    安全推出。

    在回執中選擇 退出來源，或在“設定”中啟用自動推出。只有匯入無錯誤時才會自動推出。

安全說明

  • SD Card Import 拷貝檔案，不會抹掉記憶卡。
  • 啟用便攜回執後，SD Card Import 僅在來源上寫入隱藏的 .sd-import 台帳。已鎖定和唯讀來源會繼續匯入，並顯示警告。
  • 已匯入檔案會在之後跳過。仍然匯入 僅適用於從便攜歷史識別的檔案。如果來源檔案在掃描後改變，SD Card Import 會要求重新掃描，不會使用過期歷史。
  • SD Card Import 不會覆寫目的地中內容不同的檔案。一般檔名衝突會加上後綴。Insta360 錄影發生衝突時會略過，以保留原始檔名；請在複製前選擇其他目的地。
  • 將 App 保留在 Applications 中，以使用背景記憶卡提示。

鍵盤快速鍵

  • Command-I：打開匯入。
  • Command-1 至 Command-3：匯入、歷史記錄、設定。
  • Control-Tab：下一個面板。
  • Command-R：重新整理歷史。
  • Command-,：設定。

如果匯入沒有自動開始。

確認在「設定 > 通用」中啟用記憶卡掛載時顯示提示，手動開啟 SD Card Import，再選擇從記憶卡匯入…。如果問題持續，請匯出診斷並聯絡支援。
