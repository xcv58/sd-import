使用指南

設定一次目的位置，每次拷貝前預覽記憶卡，清楚記錄 SD Import 已匯入的內容。

本指南截圖展示直接下載版 SD Import。SD Card Import 是 App Store 版；請參閱獲取方式與價格及購買與恢復幫助。

使用 SD Card Import？從 Mac App Store 安裝，然後選擇來源檔案夾和目標檔案夾。下方流程展示直接下載版 SD Import。

快速開始。

大多數使用者只需安裝一次、設定一次目的位置，並在每次插卡時檢查預覽。

1

安裝

下載已簽名的 DMG，打開後將 SD Import.app 拖入 Applications。

2

設定檔案夾

打開“設定”，選擇照片和影片目的位置，還可啟用自動推出來源裝置或便攜匯入回執。便攜回執會在可寫來源上寫入隱藏的 .sd-import 台帳，讓其他 Mac 避免重複匯入。

3

匯入

插卡並檢查預覽，拷貝進度完成前保持連接。從便攜歷史識別的檔案會標記為 另一台 Mac；拷貝前會重新檢查歷史，重建目標計劃時 仍然匯入 保持啟用。完成後可從回執推出來源裝置。

從記憶卡匯入。

記憶卡掛載時 SD Import 可自動出現，也可以打開App並選擇 從記憶卡匯入…。

  1. 1

    連接記憶卡。

    插入 SD 卡或連接相機讀卡器。

  2. 2

    檢查掃描結果。

    檢查新增、已匯入、不支援或存在衝突的檔案。

  3. 3

    開始拷貝。

    確認目的位置，保持來源裝置連接直到匯入完成。

  4. 4

    安全推出。

    在回執中選擇 退出來源，或在“設定”中啟用自動推出。只有匯入無錯誤時才會自動推出。

安全說明

  • SD Import 拷貝檔案，不會抹掉記憶卡。
  • 啟用便攜回執後，SD Import 僅在來源上寫入隱藏的 .sd-import 台帳。已鎖定和唯讀來源會繼續匯入，並顯示警告。
  • 已匯入檔案會在之後跳過。仍然匯入 僅適用於從便攜歷史識別的檔案。如果來源檔案在掃描後改變，SD Import 會要求重新掃描，不會使用過期歷史。
  • 如果目的位置已有不同內容的同名檔案，SD Import 會添加後綴，保留兩個檔案。
  • 將App保留在 Applications 中，以便正確安裝更新。

鍵盤快速鍵

  • Command-I：打開匯入。
  • Command-1 至 Command-4：匯入、歷史、設定、診斷。
  • Control-Tab：下一個面板。
  • Command-R：重新整理歷史。
  • Command-,：設定。

如果匯入沒有自動開始。

確保已在“設定”中啟用 記憶卡掛載時提示，手動打開 SD Import，再選擇 從記憶卡匯入…。如果問題持續，請導出診斷並聯繫支援。
