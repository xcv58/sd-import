SD Card Import · Mac App Store

SD Card Import 支援運行 macOS 14 或更新版本的 Apple 晶片和 Intel Mac。可在 Mac App Store 下載。

可免費成功完成一次匯入。之後一次支付 9.99 美元（美國價格）即可解鎖無限次完成匯入，並支援家人共享。掃描與預覽始終免費，各地定價可能不同，無訂閱。

通過 App Store 安裝 SD Card Import，然後在App中選擇來源檔案夾和目標檔案夾。Apple 負責安裝、更新和購買。

SD Import · 免費直接下載

下載 DMG，將App移到“應用程式”，然後在首次啟動時選擇匯入檔案夾。

要求：Apple 晶片 Mac、macOS 14 或更新版本，以及所選照片或影片目的位置的足夠可用空間。

1

下載

從最新的 GitHub Release 獲取 SD-Import.dmg。

2

拷貝到“應用程式”

打開 DMG，將 SD Import.app 拖入 Applications。

3

選擇檔案夾

打開App，在首次設定中選擇來源檔案夾和目標檔案夾。

下載 Apple 晶片 Mac 版 查看最新 GitHub Release

Gatekeeper 與首次啟動。

如果 macOS 提示App來自網際網路，請選擇“打開”。如果首次啟動被阻止，請打開“系統設定”中的“隱私權與安全性”，為 SD Import 選擇“仍要打開”。

系統要求

  • Apple 晶片 Mac。
  • macOS 14 或更新版本。
  • SD 卡、讀卡器、相機中已掛載的記憶卡，或所選來源檔案夾。
  • 所選照片或影片目的位置有足夠可用空間。
