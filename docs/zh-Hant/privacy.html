隱私權政策

最後更新：2026-09-10。本政策涵蓋 SD Import（直接下載版）和 SD Card Import（App Store 版），它們是在本地將 SD 卡或所選來源檔案夾中的照片和影片拷貝到目的位置的 macOS 工具。

本地保存的資料

兩個版本都在 Mac 本地保存App設定、檔案夾權限、匯入歷史和用於跳過重複匯入的記錄。直接下載版使用 ~/Library/Application Support/SD Import/state.sqlite。SD Card Import 使用與記憶卡偵測輔助程式共享的本地 App Group 容器。兩個版本也可能通過 macOS UserDefaults 保存常規偏好設定。

可選的便攜匯入回執

啟用便攜匯入回執後，App會在可寫來源上建立或追加 .sd-import/imported-v1.jsonl。此隱藏台帳包含帶版本的檔案指紋、相對來源路徑、大小、修改和匯入時間戳及校驗和，便於另一台 Mac 避免重複匯入。它不包含目標路徑、使用者名稱或媒體內容。此選項預設關閉；唯讀來源會繼續處理而不寫入便攜歷史；台帳訪問會拒絕通過符號連結重定向到所選來源之外。

網絡使用

如果已安裝的發行版配置了更新檢查，直接下載版會使用 Sparkle 連接本倉庫托管在 GitHub Release 上的 appcast。SD Card Import 通過 App Store 接收更新，不包含 Sparkle。

App Store 購買

Apple 處理 SD Card Import 的購買和恢復。App通過 StoreKit 交易及權益資訊確定購買權限，並在本地保存購買權限狀態和免費匯入使用情況。我們不會收到付款卡資訊。

無自動遙測

兩個版本都不會向維護者發送分析資料、遙測、匯入歷史、媒體檔案、檔案夾列表或崩潰報告。診斷導出由你選擇，並經過隱私權處理。直接下載版可以顯示 macOS 崩潰報告檔案夾，或導出最新的本地App崩潰報告。App Store 版無法瀏覽系統崩潰報告。兩個版本都不會自動上傳崩潰報告。
