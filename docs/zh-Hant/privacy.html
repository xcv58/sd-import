隱私權政策

最後更新：2026-09-30。本政策適用於 SD Card Import，這是一款從 SD 卡或所選來源資料夾複製照片與影片的 macOS App。

本地保存的資料

你的設定、資料夾存取權限和匯入記錄都留在 Mac 上。App 會利用這些記錄辨識已匯入的檔案。

技術細節

SD Card Import 將設定、資料夾權限、匯入歷史與重複偵測記錄儲存在你的 Mac 本機。它使用與記憶卡偵測輔助程式共用的 App Group 容器，也可能透過 macOS UserDefaults 儲存偏好設定。

讓另一台 Mac 辨識已匯入的檔案

這項功能預設關閉。啟用後，App 會在可寫入的記憶卡或來源資料夾儲存隱藏的匯入記錄，讓另一台 Mac 辨識已拷貝的檔案。記錄不含照片或影片內容、目標資料夾路徑或使用者名稱。唯讀來源仍可匯入，不會寫入這些記錄。

技術細節

啟用在來源儲存匯入記錄後，App 會在可寫入的來源建立或更新 .sd-import/imported-v1.jsonl。這個隱藏檔案包含有版本資訊的檔案識別資料、相對來源路徑、大小、修改與匯入時間，以及檢查資料是否完整的檢查碼，讓另一台 Mac 避免重複匯入。它不包含目標路徑、使用者名稱或照片、影片內容。這項功能預設關閉；唯讀來源仍可匯入，不會寫入這些記錄。App 會拒絕透過符號連結讀寫所選來源以外的位置。

網絡使用

Apple 負責 App Store 下載、更新和購買。開啟網站連結或傳送意見時，會使用你的瀏覽器或郵件 App。SD Card Import 不會上傳你的照片或影片。

App Store 購買

Apple 負責處理 SD Card Import 的購買和恢復購買。App 會檢查 Apple 驗證過的購買與使用權限記錄，確認 14 天試用或終身使用權限是否有效。試用期從經驗證的購買日期起算。我們不會收到你的付款卡資料。

不會自動傳送使用報告

SD Card Import 不會自動向開發者傳送使用情況、匯入記錄、照片或影片、資料夾清單或當機報告。只有在你要求時才會匯出診斷報告，其中可能包含資料夾名稱、路徑和錯誤訊息。分享前請先檢查並移除私人資訊。App 無法瀏覽系統當機報告。

支援請求

透過電子郵件聯絡支援時，您自行選擇經郵件服務供應商傳送的訊息和附件。公開的 GitHub 議題對所有人可見。請勿在公開議題中附上私人照片、影片、完整記憶卡傾印、憑證或未遮蔽的日誌。

聯繫方式

隱私權與支援問題請發郵件至 sd-card-import@jenny.media。
