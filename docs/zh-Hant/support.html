支援從預覽開始。

支援 SD Import（直接下載版）與 SD Card Import（App Store 版）。提供App版本、macOS 版本、目的位置狀態和所選任務摘要，有助於診斷大多數匯入問題。

聯繫方式

支援郵箱：i@xcv58.com

公開錯誤與功能建議：GitHub Issues

安全報告：請遵循 SECURITY.md，不要為疑似漏洞提交公開問題。

傳送郵件取得支援 提交公開問題

應提供的資訊

  • App名稱、版本和構建號：SD Import 或 SD Card Import。
  • macOS 版本和 Mac 型號。
  • 相機或記憶卡品牌、檔案系統和讀卡器類型。
  • 匯入是自動還是手動開始的。
  • 預覽顯示了什麼，以及匯入後發生了什麼。

導出診斷。

診斷導出由你選擇，並經過隱私權處理，不包含媒體檔案、檔案名稱和完整來源路徑或目標路徑。

1

打開診斷

在任一版本中，從側邊欄選擇“診斷”。

2

導出

選擇“拷貝診斷”或“導出診斷”。分享前請檢查檔案。

3

有選擇地附上檔案

僅分享必要內容。不要附上私人媒體、完整記憶卡轉儲或憑證。

崩潰報告。

兩個版本都不會自動上傳崩潰報告。App崩潰時，macOS 可能保存本地報告，你可以選擇分享。

~/Library/Logs/DiagnosticReports/

在直接下載版中，使用“診斷”中的“顯示崩潰報告”或“導出最新崩潰報告”。App Store 版無法瀏覽系統崩潰報告；如支援人員要求，請使用 macOS“主控台”查找。分享前請檢查報告。

購買與恢復使用權限

SD Card Import 可免費完成一次匯入。購買 SD Import Unlimited 可解鎖無限次完成匯入，並支援家人共享。掃描與預覽始終免費。直接下載版 SD Import 免費且無App內購買。

在 SD Card Import 中打開“設定”>“購買”，選擇“恢復購買”。使用購買時的 Apple 帳號或符合條件的家人共享帳號。若仍未獲得權限，請聯繫支援，提供App版本和購買頁面顯示的內容。

重新打開已關閉的視窗

在 SD Card Import 中選擇“視窗”>“顯示 SD Card Import”，選擇“檔案”>“從記憶卡匯入”（Command-I），或按一下Dock中的App圖像。
