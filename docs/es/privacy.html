Política de privacidad

Última actualización: 2026-09-10. Esta política cubre SD Import (descarga directa) y SD Card Import (edición App Store), utilidades locales de macOS para copiar fotos y vídeos de tarjetas SD o carpetas de origen elegidas.

Datos guardados localmente

Ambas ediciones guardan en tu Mac los ajustes, permisos de carpetas, historial de importación y registros para evitar duplicados. La edición directa usa ~/Library/Application Support/SD Import/state.sqlite. SD Card Import usa un contenedor local App Group compartido con su asistente de detección de tarjetas. Ambas pueden guardar preferencias comunes mediante UserDefaults de macOS.

Recibos portátiles de importación opcionales

Si activas los recibos portátiles, la app crea o amplía .sd-import/imported-v1.jsonl en orígenes con permiso de escritura. El registro oculto contiene huellas de archivos con versión, rutas de origen relativas, tamaños, marcas de tiempo de modificación e importación y sumas de verificación para evitar duplicados en otro Mac. No contiene rutas de destino, nombres de usuario ni contenido multimedia. Está desactivado por defecto; los orígenes de solo lectura continúan sin escribir historial portátil y el acceso al registro rechaza redirecciones mediante enlaces simbólicos fuera del origen seleccionado.

Uso de la red

La edición directa usa Sparkle para buscar actualizaciones cuando está configurado en la versión instalada. Las consultas contactan con el appcast de este repositorio alojado en GitHub Releases. SD Card Import se actualiza mediante el App Store y no incluye Sparkle.

Compras en el App Store

Apple procesa las compras y restauraciones de SD Card Import. La app usa información de transacciones y derechos de StoreKit para determinar el acceso comprado. Guarda localmente ese estado y el uso de la importación gratuita. No recibimos datos de tarjetas de pago.

Sin telemetría automática

Ninguna edición envía al mantenedor análisis, telemetría, historial de importación, medios, listas de carpetas ni informes de fallos. La exportación del diagnóstico es voluntaria y oculta datos privados. La edición directa permite mostrar la carpeta de informes de macOS o exportar el último informe local de la app. La edición App Store no puede explorar informes del sistema. Ninguna los carga automáticamente.

Solicitudes de soporte

Las incidencias públicas de GitHub son visibles para todos. No adjuntes fotos o vídeos privados, volcados completos de tarjetas, credenciales ni registros sin ocultar datos privados.
