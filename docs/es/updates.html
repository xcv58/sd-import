Mantén tu app actualizada.

SD Card Import recibe actualizaciones del App Store. Abre el App Store y consulta Actualizaciones.

Las instrucciones y descargas siguientes son para SD Import, la edición directa que usa Sparkle y GitHub Releases. Obtener la edición App Store.

Comprobar manualmente

  1. Abre SD Import desde Aplicaciones.
  2. Elige SD Import > Buscar actualizaciones….
  3. Si Sparkle no muestra actualizaciones, la app está al día con el canal público.

Verificar en GitHub

Compara la versión instalada con la última de GitHub. Las versiones públicas incluyen SD-Import.dmg, SD-Import.zip, appcast.xml y notas de la versión.

Última versión en GitHub

Si una actualización parece incorrecta.

Usa primero la última versión pública y comparte el diagnóstico si las importaciones siguen sin funcionar como esperabas.

Comprueba de nuevo las actualizaciones, compara tu versión con la última de GitHub, reinstala el DMG más reciente si hace falta y contacta con soporte con el resumen de la vista previa y el diagnóstico exportado.
