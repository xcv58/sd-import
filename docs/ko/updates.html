앱을 최신 상태로 유지하세요.

SD Card Import는 App Store에서 업데이트를 받습니다. App Store를 열고 업데이트를 확인하세요.

아래 안내와 다운로드는 Sparkle과 GitHub Releases를 사용하는 직접 다운로드 에디션 SD Import용입니다. App Store 에디션 받기.

수동 확인

  1. 응용 프로그램에서 SD Import를 여세요.
  2. SD Import > 업데이트 확인…을 선택하세요.
  3. Sparkle에 사용 가능한 업데이트가 없다고 나오면 공개 피드의 최신 버전입니다.

GitHub에서 확인

설치된 앱 버전과 최신 GitHub Release를 비교하세요. 공개 릴리스에는 SD-Import.dmg, SD-Import.zip, appcast.xml 및 릴리스 노트가 포함됩니다.

최신 GitHub Release

업데이트가 이상해 보이는 경우.

먼저 최신 공개 버전을 사용하고, 가져오기가 여전히 예상대로 작동하지 않으면 진단 정보를 공유하세요.

업데이트를 다시 확인하고 설치된 버전을 최신 GitHub Release와 비교하세요. 필요하면 최신 DMG를 다시 설치한 뒤 미리보기 요약과 내보낸 진단 정보를 지원팀에 보내세요.
