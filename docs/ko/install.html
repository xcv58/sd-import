Mac App Store의 SD Card Import 또는 Apple Silicon Mac용 무료 직접 다운로드 에디션 SD Import를 선택하세요.

SD Card Import · Mac App Store

SD Card Import는 macOS 14 이상의 Apple Silicon 및 Intel Mac을 지원합니다. Mac App Store에서 다운로드하세요.

성공적으로 완료한 가져오기 1회는 무료입니다. 이후 미국 가격 미화 9.99달러를 한 번 결제하면 가져오기 완료 횟수가 무제한이 되며 가족 공유를 지원합니다. 스캔과 미리보기는 계속 무료입니다. 지역별 가격은 다를 수 있습니다. 구독은 없습니다.

App Store에서 SD Card Import를 설치한 뒤 앱에서 원본 및 대상 폴더를 선택하세요. Apple이 설치, 업데이트, 구매를 관리합니다.
