개인정보 처리방침

최종 업데이트: 2026-09-10. 이 방침은 SD Import(직접 다운로드)와 SD Card Import(App Store 에디션)에 적용됩니다. 두 앱은 SD 카드 또는 선택한 원본 폴더에서 사진과 동영상을 복사하는 로컬 macOS 유틸리티입니다.

로컬에 저장되는 데이터

두 에디션은 앱 설정, 폴더 권한, 가져오기 기록, 중복 방지 기록을 Mac에 로컬로 저장합니다. 직접 다운로드 에디션은 ~/Library/Application Support/SD Import/state.sqlite을 사용합니다. SD Card Import는 카드 감지 도우미와 공유하는 로컬 App Group 컨테이너를 사용합니다. 두 앱 모두 macOS UserDefaults로 일반 환경설정을 저장할 수도 있습니다.

선택 사항인 휴대용 가져오기 기록

휴대용 가져오기 기록을 켜면 앱은 쓰기 가능한 원본에 .sd-import/imported-v1.jsonl을 만들거나 덧붙입니다. 숨김 기록에는 다른 Mac에서 중복을 피할 수 있도록 버전이 있는 파일 지문, 상대 원본 경로, 크기, 수정 및 가져오기 시각, 검증 체크섬이 포함됩니다. 대상 경로, 사용자 이름, 미디어 내용은 포함하지 않습니다. 기본값은 꺼짐입니다. 읽기 전용 원본은 휴대용 기록을 쓰지 않고 계속 처리하며, 기록 접근 시 선택한 원본 밖으로 향하는 심볼릭 링크 리디렉션을 거부합니다.

네트워크 사용

직접 다운로드 에디션은 설치된 릴리스에 설정되어 있으면 Sparkle로 업데이트를 확인합니다. 이 확인은 GitHub Releases에 호스팅된 이 저장소의 appcast에 접속합니다. SD Card Import는 App Store에서 업데이트를 받으며 Sparkle을 포함하지 않습니다.

App Store 구입

Apple이 SD Card Import의 구매와 복원을 처리합니다. 앱은 StoreKit 거래 및 권한 정보로 구매한 이용 권한을 확인하고, 해당 상태와 무료 가져오기 사용량을 로컬에 저장합니다. 개발자는 결제 카드 정보를 받지 않습니다.

자동 원격 측정 없음

어떤 에디션도 분석 정보, 원격 측정, 가져오기 기록, 미디어, 폴더 목록 또는 충돌 보고서를 관리자에게 보내지 않습니다. 진단 정보 내보내기는 선택 사항이며 비공개 정보를 가립니다. 직접 다운로드 에디션은 macOS 충돌 보고서 폴더를 표시하거나 최신 로컬 앱 충돌 보고서를 내보낼 수 있습니다. App Store 에디션은 시스템 충돌 보고서를 탐색할 수 없습니다. 어떤 에디션도 보고서를 자동으로 업로드하지 않습니다.
