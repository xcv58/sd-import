도움이 필요하신가요?
어떤 사진과 동영상을 가져올 수 있나요?

SD Card Import는 일반적인 RAW, JPEG, 동영상 형식을 인식합니다. 스캔 시 카메라 메타데이터 사이드카 파일과 지원하지 않는 파일도 보여 주므로 카드 내용을 확인할 수 있습니다. 전체 과정은 가이드를 참고하세요.

같은 카드를 다시 가져오면 어떻게 되나요?

SD Card Import는 가져오기 기록의 파일을 인식해 중복 복사를 건너뜁니다. 시작 전에 새 파일과 이미 가져온 파일을 확인할 수 있습니다.

파일은 어디에 저장되나요?

선택한 대상 폴더에 저장됩니다. 사진과 동영상을 함께 보관하거나 별도 대상을 사용하고, 촬영 날짜별로 정리할 수 있습니다. 복사 전에 예정된 경로를 확인하세요.

SD Card Import가 카드에서 무언가를 삭제하나요?

SD Card Import는 원본 카드의 파일을 자동으로 삭제하지 않고 미디어를 복사합니다. 가져오기가 끝나면 지원되는 이동식 카드를 안전하게 추출할 수 있습니다.

두 에디션은 어떻게 다른가요?

여기 연결된 직접 다운로드 에디션은 무료이며 MIT 라이선스의 오픈 소스입니다. 서명된 앱을 다운로드하거나 GitHub 소스 코드를 살펴볼 수 있습니다. App Store 에디션인 SD Card Import는 가져오기 1회 완료까지 무료이며, 이후 미국 가격 미화 9.99달러의 일회성 구매로 무제한 가져오기와 가족 공유를 제공합니다. 스캔과 미리보기는 계속 무료입니다.

시작하려면 무엇이 필요한가요?

macOS 14 이상의 Mac, 마운트된 카드 또는 원본 폴더, 대상의 충분한 여유 공간이 필요합니다. App Store에서 SD Card Import를 설치하고 폴더를 선택하세요. 설치 가이드에서 두 에디션을 모두 안내합니다.
