지원은 미리보기에서 시작됩니다.

SD Import(직접 다운로드)와 SD Card Import(App Store 에디션)를 지원합니다. 앱 및 macOS 버전, 대상 상태, 선택한 작업 요약을 알려주면 대부분의 가져오기 문제를 더 쉽게 진단할 수 있습니다.

포함할 정보

  • 앱 이름, 버전, 빌드: SD Import 또는 SD Card Import.
  • macOS 버전 및 Mac 모델.
  • 카메라나 카드 브랜드, 파일 시스템, 리더기 유형.
  • 가져오기가 자동 또는 수동으로 시작됐는지 여부.
  • 미리보기 내용과 가져오기 후 발생한 일.

첨부 파일 선택

필요한 내용만 공유하세요. 비공개 미디어, 카드 전체 덤프 또는 자격 증명을 첨부하지 마세요.

충돌 보고서.

어떤 에디션도 충돌 보고서를 자동으로 업로드하지 않습니다. 앱이 충돌하면 macOS가 로컬 보고서를 저장할 수 있으며, 공유 여부는 직접 선택할 수 있습니다.

~/Library/Logs/DiagnosticReports/

직접 다운로드 에디션에서는 진단에서 충돌 보고서 보기 또는 최신 충돌 보고서 내보내기를 사용하세요. App Store 에디션은 시스템 충돌 보고서를 탐색할 수 없습니다. 지원팀이 요청하면 macOS 콘솔에서 보고서를 찾아 공유 전에 검토하세요.

구매 및 이용 권한 복원

SD Card Import는 가져오기 1회 완료까지 무료입니다. SD Import Unlimited를 구매하면 가져오기 완료 횟수가 무제한이 되고 가족 공유를 지원합니다. 스캔과 미리보기는 계속 무료입니다. 직접 다운로드 에디션 SD Import는 무료이며 앱 내 구입이 없습니다.

SD Card Import에서 설정 > 구매를 열고 구입 항목 복원을 선택하세요. 구매한 Apple 계정 또는 가족 공유 자격이 있는 계정을 사용하세요. 여전히 이용할 수 없다면 앱 버전과 구매 화면의 내용을 지원팀에 알려주세요.

닫은 윈도우 다시 열기

SD Card Import에서 윈도우 > SD Card Import 보기, 파일 > 카드에서 가져오기(Command-I)를 선택하거나 Dock의 앱 아이콘을 클릭하세요.
