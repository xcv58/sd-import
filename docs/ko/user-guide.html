사용 가이드

대상을 한 번 설정하고, 복사 전마다 카드를 미리 확인하고, SD Card Import로 이미 가져온 항목의 기록을 명확히 남기세요.

빠른 시작.

대부분은 앱 설치와 대상 설정을 한 번만 하고, 카드를 넣을 때마다 미리보기를 확인하면 됩니다.

1

설치

App Store에서 SD Card Import를 설치한 뒤 앱에서 원본 및 대상 폴더를 선택하세요. Apple이 설치, 업데이트, 구매를 관리합니다.

2

폴더 설정

설정에서 사진 및 동영상 대상을 선택하고, 필요하면 자동 추출이나 휴대용 가져오기 기록을 활성화하세요. 휴대용 기록은 쓰기 가능한 원본에 숨김 기록 파일 .sd-import을 저장해 다른 Mac에서 중복 가져오기를 피하도록 합니다.

3

가져오기

카드를 삽입하고 스캔을 허용한 뒤 미리보기를 확인하세요. 휴대용 기록에서 인식한 파일에는 다른 Mac이 표시됩니다. 해당 파일을 다시 복사하려는 경우에만 그래도 가져오기를 선택하세요. 복사가 완료될 때까지 카드를 연결한 상태로 두고 안전하게 추출하세요.

카드에서 가져오기.

카드가 마운트되면 SD Card Import가 자동으로 나타날 수 있습니다. 앱을 직접 열고 카드에서 가져오기…을 선택할 수도 있습니다.

  1. 1

    카드를 연결하세요.

    SD 카드를 넣거나 카메라 카드 리더기를 연결하세요.

  2. 2

    스캔을 검토하세요.

    새 파일, 이미 가져온 파일, 지원되지 않거나 충돌하는 파일을 확인하세요.

  3. 3

    복사를 시작하세요.

    대상을 확인하고 가져오기가 끝날 때까지 원본을 연결해 두세요.

  4. 4

    안전하게 추출하세요.

    결과 화면에서 소스 추출을 선택하거나 설정에서 자동 추출을 켜세요. 자동 추출은 오류 없이 가져오기를 마친 경우에만 실행됩니다.

안전 안내

  • SD Card Import는 파일을 복사하며 카드를 지우지 않습니다.
  • 휴대용 기록을 켜면 SD Card Import는 원본에 숨김 기록 파일 .sd-import만 씁니다. 잠겼거나 읽기 전용인 원본은 경고와 함께 계속 처리합니다.
  • 이미 가져온 파일은 다음 실행부터 건너뜁니다. 그래도 가져오기은 휴대용 기록에서 인식한 파일에만 사용할 수 있습니다. 스캔 후 원본 파일이 변경되면 오래된 기록을 사용하지 않고 다시 스캔하도록 요청합니다.
  • SD Card Import는 대상에 있는 내용이 다른 파일을 덮어쓰지 않습니다. 일반 파일 이름 충돌에는 접미사를 붙입니다. Insta360 녹화 파일 충돌은 파일 이름을 유지하기 위해 건너뜁니다. 복사하기 전에 다른 대상을 선택하세요.
  • 백그라운드 카드 알림을 사용하려면 앱을 Applications에 설치된 상태로 유지하세요.

키보드 단축키

  • Command-I: 가져오기 열기.
  • Command-1~Command-3: 가져오기, 기록, 설정.
  • Control-Tab: 다음 패널.
  • Command-R: 기록 새로 고침.
  • Command-,: 설정.

가져오기가 자동으로 시작되지 않는 경우.

설정 > 일반에서 카드가 마운트되면 알림이 활성화되어 있는지 확인하고 SD Card Import를 직접 연 다음 카드에서 가져오기…를 선택하세요. 문제가 계속되면 진단을 내보내고 지원에 문의하세요.
