사용 가이드

대상을 한 번 설정하고, 복사 전마다 카드를 미리 확인하고, SD Import로 이미 가져온 항목의 기록을 명확히 남기세요.

이 가이드의 화면은 직접 다운로드 에디션 SD Import입니다. SD Card Import는 App Store 에디션입니다. 이용 방법 및 가격과 구매 및 복원 도움말을 확인하세요.

SD Card Import를 사용하시나요? Mac App Store에서 설치한 뒤 원본 및 대상 폴더를 선택하세요. 아래 과정은 직접 다운로드 에디션 SD Import를 보여 줍니다.

빠른 시작.

대부분은 앱 설치와 대상 설정을 한 번만 하고, 카드를 넣을 때마다 미리보기를 확인하면 됩니다.

1

설치

서명된 DMG를 다운로드해 열고 SD Import.app을 Applications으로 드래그하세요.

2

폴더 설정

설정에서 사진 및 동영상 대상을 선택하고, 필요하면 자동 추출이나 휴대용 가져오기 기록을 활성화하세요. 휴대용 기록은 쓰기 가능한 원본에 숨김 기록 파일 .sd-import을 저장해 다른 Mac에서 중복 가져오기를 피하도록 합니다.

3

가져오기

카드를 넣고 미리보기를 확인한 뒤 복사가 끝날 때까지 연결해 두세요. 휴대용 기록으로 인식한 파일은 다른 Mac으로 표시됩니다. 복사 전에 기록을 다시 확인하며 대상 계획을 다시 구성하는 동안에도 그래도 가져오기은 활성 상태입니다. 완료 후 결과 화면에서 원본을 추출하세요.

카드에서 가져오기.

카드가 마운트되면 SD Import가 자동으로 나타날 수 있습니다. 앱을 직접 열고 카드에서 가져오기…을 선택할 수도 있습니다.

  1. 1

    카드를 연결하세요.

    SD 카드를 넣거나 카메라 카드 리더기를 연결하세요.

  2. 2

    스캔을 검토하세요.

    새 파일, 이미 가져온 파일, 지원되지 않거나 충돌하는 파일을 확인하세요.

  3. 3

    복사를 시작하세요.

    대상을 확인하고 가져오기가 끝날 때까지 원본을 연결해 두세요.

  4. 4

    안전하게 추출하세요.

    결과 화면에서 소스 추출을 선택하거나 설정에서 자동 추출을 켜세요. 자동 추출은 오류 없이 가져오기를 마친 경우에만 실행됩니다.

안전 안내

  • SD Import는 파일을 복사하며 카드를 지우지 않습니다.
  • 휴대용 기록을 켜면 SD Import는 원본에 숨김 기록 파일 .sd-import만 씁니다. 잠겼거나 읽기 전용인 원본은 경고와 함께 계속 처리합니다.
  • 이미 가져온 파일은 다음 실행부터 건너뜁니다. 그래도 가져오기은 휴대용 기록에서 인식한 파일에만 사용할 수 있습니다. 스캔 후 원본 파일이 변경되면 오래된 기록을 사용하지 않고 다시 스캔하도록 요청합니다.
  • 대상에 이름은 같지만 내용이 다른 파일이 있으면 SD Import는 접미사를 붙여 두 파일을 모두 보존합니다.
  • 업데이트가 올바르게 설치되도록 앱을 Applications에 두세요.

키보드 단축키

  • Command-I: 가져오기 열기.
  • Command-1부터 Command-4: 가져오기, 기록, 설정, 진단.
  • Control-Tab: 다음 패널.
  • Command-R: 기록 새로 고침.
  • Command-,: 설정.

가져오기가 자동으로 시작되지 않는 경우.

설정에서 카드 마운트 시 알림이 켜져 있는지 확인하고 SD Import를 직접 연 뒤 카드에서 가져오기…을 선택하세요. 문제가 계속되면 진단 정보를 내보내고 지원팀에 문의하세요.
