サポートはプレビューの確認から。

SD Import（直接配布版）と SD Card Import（App Store 版）のサポートです。アプリと macOS のバージョン、保存先の状態、選択したジョブの概要があると、多くの取り込み問題を診断しやすくなります。

お問い合わせ

サポートメール：i@xcv58.com

公開バグ報告と機能リクエスト：GitHub Issues

セキュリティ報告は SECURITY.md に従ってください。脆弱性の疑いを公開 Issue で報告しないでください。

メールで問い合わせる 公開 Issue を作成

お知らせいただきたい情報

  • アプリ名、バージョン、ビルド：SD Import または SD Card Import。
  • macOS のバージョンと Mac のモデル。
  • カメラやカードのメーカー、ファイルシステム、リーダーの種類。
  • 取り込みが自動開始か手動開始か。
  • プレビューの表示内容と取り込み後に起きたこと。

診断情報を書き出す。

診断情報の書き出しは任意で、個人情報は伏せられます。メディア、ファイル名、ソースと保存先の完全なパスは含みません。

1

診断を開く

どちらのエディションでも、サイドバーから「診断」を選びます。

2

書き出す

「診断情報をコピー」または「診断情報を書き出す」を選びます。共有前にファイルを確認してください。

3

添付する内容を選ぶ

必要な情報だけを共有してください。私的なメディア、カード全体のダンプ、認証情報は添付しないでください。

クラッシュレポート。

どちらのエディションもクラッシュレポートを自動送信しません。クラッシュ時は macOS がローカルレポートを保存する場合があり、共有するかどうかは自分で選べます。

~/Library/Logs/DiagnosticReports/

直接配布版では「診断」から「クラッシュレポートを表示」や「最新のクラッシュレポートを書き出す」を使えます。App Store 版はシステムのクラッシュレポートを参照できません。サポートに求められた場合は macOS の「コンソール」で探し、共有前に内容を確認してください。

購入とアクセスの復元

SD Card Import は 1 回の取り込み完了まで無料です。SD Import Unlimited を購入すると取り込み完了回数が無制限になり、ファミリー共有も使えます。スキャンとプレビューは無料です。直接配布版 SD Import は無料で、アプリ内課金はありません。

SD Card Import の「設定」>「購入」で「購入を復元」を選びます。購入した Apple Account、またはファミリー共有の対象アカウントを使ってください。復元できない場合は、アプリのバージョンと購入画面の内容を添えてサポートに連絡してください。

閉じたウインドウを開き直す

SD Card Import で「ウインドウ」>「SD Card Import を表示」、または「ファイル」>「カードから取り込む」（Command-I）を選ぶか、Dock のアプリアイコンをクリックしてください。
