サポートはプレビューの確認から。

SD Card Import のサポートはこちら。状況を確認できるよう、アプリと macOS のバージョン、保存先の状態、選択したジョブの概要をお知らせください。

お問い合わせ

サポートメール：sd-card-import@jenny.media

「フィードバックを送信…」があるバージョンでは、「設定 > 一般 > フィードバックを送信…」または「ヘルプ > フィードバックを送信…」を選びます。アプリのバージョン、ビルド、macOS のバージョンを記載したメールの下書きが開きます。本文を追加し、メールアプリから送信してください。

公開バグ報告と機能リクエスト：GitHub Issues

セキュリティ報告は SECURITY.md に従ってください。脆弱性の疑いを公開 Issue で報告しないでください。

メールで問い合わせる 公開 Issue を作成

お知らせいただきたい情報

  • SD Card Import のバージョンとビルド。
  • macOS のバージョンと Mac のモデル。
  • カメラやカードのメーカー、ファイルシステム、リーダーの種類。
  • 取り込みが自動開始か手動開始か。
  • プレビューの表示内容と取り込み後に起きたこと。

診断情報を書き出す。

診断の出力は任意で、メディアファイルは含みません。フォルダ名、ボリューム名、パス、エラーの文面が残る場合があります。共有前に内容を確認し、個人情報を伏せてください。

1

診断を開く

メニューバーで「ヘルプ > 診断…」を選択します。

2

書き出す

「診断情報をコピー」または「診断情報を書き出す」を選びます。共有前にファイルを確認してください。

3

添付する内容を選ぶ

必要な情報だけを共有してください。私的なメディア、カード全体のダンプ、認証情報は添付しないでください。

クラッシュレポート。

SD Card Import はクラッシュレポートを自動送信しません。クラッシュ時に macOS がローカルに保存したレポートは、ご自身の判断で共有できます。

~/Library/Logs/DiagnosticReports/

サポートから依頼された場合は、macOS の「コンソール」でクラッシュレポートを探し、共有前に内容を確認してください。SD Card Import はシステムのクラッシュレポートを参照できません。

購入とアクセスの復元

14 日間は取り込み完了回数が無制限で無料です。その後は米国価格 9.99 米ドルの買い切りで永続的に利用でき、ファミリー共有にも対応します。スキャンとプレビューは無料です。価格は地域により異なります。トライアルは更新されず、自動的に課金されません。サブスクリプションはありません。

SD Card Import で「設定 > 一般 > 購入を復元」を選びます。購入に使用した Apple Account、または対象となるファミリー共有のアカウントを使用してください。利用できない場合は、アプリのバージョンと購入画面の内容を添えてサポートに連絡してください。

閉じたウインドウを開き直す

SD Card Import で「ウインドウ」>「SD Card Import を表示」、または「ファイル」>「カードから取り込む」（Command-I）を選ぶか、Dock のアプリアイコンをクリックしてください。
