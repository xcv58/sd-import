ユーザーガイド

保存先を一度設定し、コピー前に毎回カードを確認。SD Import の取り込み済み記録をわかりやすく残せます。

このガイドの画面は直接配布版 SD Import のものです。SD Card Import は App Store 版です。入手方法と料金、購入と復元のヘルプをご覧ください。

SD Card Import をお使いですか？Mac App Store からインストールし、ソースと保存先フォルダを選んでください。以下の手順は直接配布版 SD Import の画面です。

クイックスタート。

通常はインストールと保存先の設定を一度行い、カードを挿すたびにプレビューを確認するだけです。

1

インストール

署名済み DMG をダウンロードして開き、SD Import.app を Applications にドラッグします。

2

フォルダを設定

「設定」で写真と動画の保存先を選び、必要に応じてソースの自動取り出しやポータブル取り込み記録を有効にします。ポータブル記録は書き込み可能なソースに非表示の台帳 .sd-import を保存し、ほかの Mac で重複取り込みを防ぎます。

3

取り込み

カードを挿してプレビューを確認し、コピーが終わるまで接続を保ちます。ポータブル履歴で認識したファイルには 別の Mac と表示されます。コピー前に履歴を再確認し、保存先の計画を再構築する間も それでも読み込む は有効です。完了したら結果画面からソースを取り出してください。

カードから取り込む。

カードをマウントすると SD Import を自動表示できます。アプリを開いて カードから読み込む… を選ぶこともできます。

  1. 1

    カードを接続。

    SD カードを挿すか、カメラのカードリーダーを接続します。

  2. 2

    スキャンを確認。

    新規、取り込み済み、非対応、競合のあるファイルを確認します。

  3. 3

    コピーを開始。

    保存先を確認し、取り込みが完了するまでソースの接続を保ちます。

  4. 4

    安全に取り出す。

    結果画面の 読み込み元を取り出す を選ぶか、「設定」で自動取り出しを有効にします。自動取り出しはエラーのない取り込み後にのみ実行されます。

安全上の注意

  • SD Import はファイルをコピーし、カードを消去しません。
  • ポータブル記録を有効にすると、SD Import はソースに非表示の台帳 .sd-import だけを書き込みます。ロック済みや読み取り専用のソースでは警告を表示して処理を続けます。
  • 取り込み済みファイルは次回以降スキップします。それでも読み込む はポータブル履歴で認識したファイルにのみ使えます。スキャン後にソースファイルが変わった場合、古い履歴を使わず再スキャンを求めます。
  • 保存先に内容の異なる同名ファイルがある場合、SD Import は末尾に文字を追加して両方を残します。
  • 更新を正しくインストールできるよう、アプリは Applications に置いてください。

キーボードショートカット

  • Command-I：取り込みを開く。
  • Command-1 から Command-4：取り込み、履歴、設定、診断。
  • Control-Tab：次のパネル。
  • Command-R：履歴を更新。
  • Command-,：設定。

取り込みが自動で始まらない場合。

「設定」で カードのマウント時に通知 が有効か確認し、SD Import を手動で開いて カードから読み込む… を選びます。問題が続く場合は診断情報を書き出してサポートに連絡してください。
