お困りですか？
どの写真や動画を取り込めますか？

SD Card Import は一般的な RAW、JPEG、動画形式を認識します。スキャンではカメラのメタデータのサイドカーファイルや非対応ファイルも表示し、カードの内容を確認できます。詳しい手順はガイドをご覧ください。

同じカードをもう一度取り込むとどうなりますか？

SD Card Import は履歴に記録されたファイルを認識し、重複コピーをスキップします。開始前に、新しい項目と取り込み済みの項目を確認できます。

ファイルはどこに保存されますか？

選んだ保存先フォルダです。写真と動画をまとめたり、別々の保存先を使ったり、撮影日ごとに整理したりできます。コピー前に予定のパスを確認してください。

SD Card Import はカードの内容を削除しますか？

SD Card Import は元のカードのファイルを自動削除せず、メディアをコピーします。取り込み後は、対応する取り外し可能なカードを安全に取り出せます。

2 つのエディションの違いは？

ここで案内している直接配布版は無料で、MIT ライセンスのオープンソースです。署名済みアプリをダウンロードするか、GitHub のソースコードを確認できます。App Store 版の SD Card Import は 1 回の取り込み完了まで無料。その後は米国価格 9.99 米ドルの買い切りで回数無制限になり、ファミリー共有に対応します。スキャンとプレビューは無料のままです。

始めるには何が必要ですか？

macOS 14 以降の Mac、マウント済みのカードまたはソースフォルダ、保存先の十分な空き容量が必要です。App Store から SD Card Import をインストールし、フォルダを選んでください。インストールガイドでは両エディションを説明しています。
