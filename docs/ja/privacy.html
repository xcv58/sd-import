プライバシーポリシー

最終更新：2026-09-10。本ポリシーは SD Import（直接配布版）と SD Card Import（App Store 版）に適用されます。両アプリは、SD カードや選択したソースフォルダから写真と動画をコピーするローカルの macOS ユーティリティです。

ローカルに保存するデータ

両エディションは、設定、フォルダのアクセス許可、取り込み履歴、重複を避けるための記録を Mac 内に保存します。直接配布版は ~/Library/Application Support/SD Import/state.sqlite を使用します。SD Card Import はカード検出ヘルパーと共有するローカルの App Group コンテナを使います。また、通常の環境設定を macOS UserDefaults に保存する場合があります。

任意のポータブル取り込み記録

ポータブル取り込み記録を有効にすると、書き込み可能なソースに .sd-import/imported-v1.jsonl を作成または追記します。非表示の台帳には、別の Mac で重複を避けるため、バージョン付きファイル指紋、相対ソースパス、サイズ、変更日時、取り込み日時、検証用チェックサムが含まれます。保存先パス、ユーザー名、メディアの内容は含みません。初期状態では無効です。読み取り専用ソースではポータブル履歴を書かずに続行し、台帳へのアクセスは選択したソース外へのシンボリックリンクによる転送を拒否します。

ネットワークの利用

直接配布版は、インストール済みのリリースで設定されている場合、Sparkle で更新を確認します。確認先は、このリポジトリの GitHub Releases に置かれた appcast です。SD Card Import は App Store から更新を受け取り、Sparkle を含みません。

App Store での購入

SD Card Import の購入と復元は Apple が処理します。アプリは StoreKit の取引情報と権利情報から購入済みアクセスを判断し、その状態と無料取り込みの使用状況をローカルに保存します。支払いカードの情報を当方が受け取ることはありません。

自動テレメトリなし

どちらのエディションも、分析データ、テレメトリ、取り込み履歴、メディア、フォルダ一覧、クラッシュレポートを管理者に送信しません。診断情報の書き出しは任意で、個人情報は伏せられます。直接配布版は macOS のクラッシュレポートフォルダの表示や、最新のローカルアプリレポートの書き出しができます。App Store 版はシステムのクラッシュレポートを参照できません。どちらも自動アップロードしません。

サポートへの連絡

公開 GitHub Issue は誰でも閲覧できます。私的な写真や動画、カード全体のダンプ、認証情報、個人情報を伏せていないログは添付しないでください。
