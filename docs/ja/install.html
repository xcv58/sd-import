Mac App Store の SD Card Import、または Apple シリコン搭載 Mac 向けの無料の直接配布版 SD Import を選べます。

SD Card Import · Mac App Store

SD Card Import は macOS 14 以降の Apple シリコンおよび Intel 搭載 Mac に対応。Mac App Store でダウンロードできます。

正常に完了した取り込み 1 回まで無料です。その後は米国価格 9.99 米ドルの買い切りで、取り込み完了回数が無制限になり、ファミリー共有も使えます。スキャンとプレビューは無料です。価格は地域により異なります。サブスクリプションはありません。

App Store から SD Card Import をインストールし、アプリ内でソースと保存先のフォルダを選んでください。インストール、更新、購入は Apple が管理します。

App Store 版を見る · 購入と復元のヘルプ

SD Import · 無料の直接ダウンロード

DMG をダウンロードし、アプリを「アプリケーション」に移動して、初回起動時に取り込み用フォルダを選びます。

必要条件：Apple シリコン搭載 Mac、macOS 14 以降、写真または動画の保存先に十分な空き容量。

1

ダウンロード

最新の GitHub Release から SD-Import.dmg を入手します。

2

「アプリケーション」にコピー

DMG を開き、SD Import.app を Applications にドラッグします。

3

フォルダを選択

アプリを開き、初回設定でソースと保存先のフォルダを選びます。

Apple シリコン搭載 Mac 向けにダウンロード 最新の GitHub Release を見る

Gatekeeper と初回起動。

macOS にインターネットからダウンロードしたアプリと表示されたら「開く」を選びます。起動がブロックされた場合は「システム設定」の「プライバシーとセキュリティ」で SD Import の「このまま開く」を選んでください。

必要条件

  • Apple シリコン搭載 Mac。
  • macOS 14 以降。
  • SD カード、カードリーダー、カメラ経由でマウントしたカード、または選択したソースフォルダ。
  • 写真または動画の保存先に十分な空き容量。
