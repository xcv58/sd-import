アプリを最新に。

SD Card Import は App Store から更新を受け取ります。App Store を開いて「アップデート」を確認してください。

以下の説明とダウンロードは、Sparkle と GitHub Releases を使う直接配布版 SD Import 向けです。App Store 版を入手。

手動で確認

  1. 「アプリケーション」から SD Import を開きます。
  2. SD Import > アップデートを確認… を選びます。
  3. Sparkle が更新なしと表示した場合、公開フィードで提供される最新の状態です。

GitHub で確認

インストール済みバージョンと最新の GitHub Release を比べてください。公開リリースには SD-Import.dmg、SD-Import.zip、appcast.xml、リリースノートが含まれます。
