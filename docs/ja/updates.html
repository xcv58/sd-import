アプリを最新に。

SD Card Import は App Store から更新を受け取ります。App Store を開いて「アップデート」を確認してください。

手動で確認

  1. Mac で App Store を開きます。
  2. サイドバーで「アップデート」を選択します。
  3. SD Card Import のアップデートが表示されたら「アップデート」を選択します。

バージョン履歴

SD Card Import の App Store ページで最新バージョンとリリースノートを確認できます。

SD Card Import を入手

更新がおかしいと思ったら。

まず最新の公開版を使い、それでも取り込みが期待どおりに動作しない場合は診断情報を共有してください。

まず App Store の「アップデート」を確認してください。問題が続く場合は、インストール済みアプリのバージョン、プレビューの概要、「ヘルプ > 診断…」から書き出したファイルを添えてサポートにご連絡ください。
