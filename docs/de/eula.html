Endbenutzer-Lizenzvereinbarung

SD Import ist kostenlos und unter der MIT-Lizenz quelloffen.

Diese Seite beschreibt SD Import, die kostenlose direkte Edition. Angaben zu Verfügbarkeit und Kauf von SD Card Import findest du bei der App-Store-Edition.

Lizenzerteilung

Du darfst SD Import unter der MIT-Lizenz verwenden, kopieren, ändern, zusammenführen, veröffentlichen, verbreiten, unterlizenzieren und Kopien verkaufen, sofern Urheberrechts- und Lizenzhinweise in Kopien oder wesentlichen Teilen der Software enthalten bleiben.

Keine Gewährleistung

SD Import wird „wie besehen“ ohne ausdrückliche oder stillschweigende Gewährleistung bereitgestellt, einschließlich Marktgängigkeit, Eignung für einen bestimmten Zweck und Nichtverletzung von Rechten Dritter.

Sicherheit der Quellmedien

SD Import ist zum Kopieren von Quellkarten und -ordnern vorgesehen, nicht zum Löschen oder Ändern von Kartendateien. Du bleibst für Sicherungen und die Prüfung der Zielkopien vor dem Formatieren von Karten verantwortlich.
