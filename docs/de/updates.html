Halte deine App aktuell.

SD Card Import erhält Updates über den App Store. Öffne den App Store und prüfe Updates.

Die folgenden Anweisungen und Downloads gelten für SD Import, die direkte Edition mit Sparkle und GitHub Releases. Zur App-Store-Edition.

Manuell prüfen

  1. Öffne SD Import aus Programme.
  2. Wähle SD Import > Nach Updates suchen….
  3. Meldet Sparkle kein verfügbares Update, ist die App für den öffentlichen Updatekanal aktuell.

Auf GitHub prüfen

Vergleiche die installierte Version mit dem neuesten GitHub-Release. Öffentliche Releases enthalten SD-Import.dmg, SD-Import.zip, appcast.xml und Versionshinweise.

Neuestes GitHub-Release

Wenn ein Update fehlerhaft wirkt.

Nutze zuerst die neueste öffentliche Version und teile die Diagnose, falls Importe weiterhin nicht wie erwartet funktionieren.

Prüfe erneut auf Updates, vergleiche deine Version mit dem neuesten GitHub-Release und installiere bei Bedarf die neueste DMG-Datei erneut. Kontaktiere dann den Support mit Vorschauzusammenfassung und Diagnoseexport.
