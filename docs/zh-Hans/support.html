支持从预览开始。

支持 SD Import（直接下载版）与 SD Card Import（App Store 版）。提供应用版本、macOS 版本、目标位置状态和所选任务摘要，有助于诊断大多数导入问题。

联系方式

支持邮箱：i@xcv58.com

公开错误与功能建议：GitHub Issues

安全报告：请遵循 SECURITY.md，不要为疑似漏洞提交公开问题。

发送邮件获取支持 提交公开问题

应提供的信息

  • 应用名称、版本和构建号：SD Import 或 SD Card Import。
  • macOS 版本和 Mac 型号。
  • 相机或存储卡品牌、文件系统和读卡器类型。
  • 导入是自动还是手动开始的。
  • 预览显示了什么，以及导入后发生了什么。

导出诊断。

诊断导出由你选择，并经过隐私处理，不包含媒体文件、文件名和完整源路径或目标路径。

1

打开诊断

在任一版本中，从侧边栏选择“诊断”。

2

导出

选择“拷贝诊断”或“导出诊断”。分享前请检查文件。

3

有选择地附上文件

仅分享必要内容。不要附上私人媒体、完整存储卡转储或凭据。

崩溃报告。

两个版本都不会自动上传崩溃报告。应用崩溃时，macOS 可能保存本地报告，你可以选择分享。

~/Library/Logs/DiagnosticReports/

在直接下载版中，使用“诊断”中的“显示崩溃报告”或“导出最新崩溃报告”。App Store 版无法浏览系统崩溃报告；如支持人员要求，请使用 macOS“控制台”查找。分享前请检查报告。

购买与恢复使用权限

SD Card Import 可免费完成一次导入。购买 SD Import Unlimited 可解锁无限次完成导入，并支持家人共享。扫描与预览始终免费。直接下载版 SD Import 免费且无应用内购买。

在 SD Card Import 中打开“设置”>“购买”，选择“恢复购买”。使用购买时的 Apple 账户或符合条件的家人共享账户。若仍未获得权限，请联系支持，提供应用版本和购买页面显示的内容。

重新打开已关闭的窗口

在 SD Card Import 中选择“窗口”>“显示 SD Card Import”，选择“文件”>“从存储卡导入”（Command-I），或点击程序坞中的应用图标。
