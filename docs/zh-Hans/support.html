支持从预览开始。

获取 SD Card Import 帮助。请提供应用版本、macOS 版本、目标文件夹状态和所选任务摘要，以便我们了解发生了什么。

联系方式

支持邮箱：sd-card-import@jenny.media

在提供“发送反馈…”的应用版本中，选择“设置 > 通用 > 发送反馈…”或“帮助 > 发送反馈…”。这会打开填写了应用版本、构建号和 macOS 版本的邮件草稿。添加消息后，从邮件应用发送。

公开错误与功能建议：GitHub Issues

安全报告：请遵循 SECURITY.md，不要为疑似漏洞提交公开问题。

发送邮件获取支持 提交公开问题

应提供的信息

  • SD Card Import 版本及构建号。
  • macOS 版本和 Mac 型号。
  • 相机或存储卡品牌、文件系统和读卡器类型。
  • 导入是自动还是手动开始的。
  • 预览显示了什么，以及导入后发生了什么。

导出诊断。

诊断导出是可选的，不包含媒体文件。文件夹名称、宗卷名称、路径和错误文本可能仍会保留。分享前请检查并隐去私人信息。

1

打开诊断

在菜单栏中选择“帮助 > 诊断…”。

2

导出

选择“拷贝诊断”或“导出诊断”。分享前请检查文件。

3

有选择地附上文件

仅分享必要内容。不要附上私人媒体、完整存储卡转储或凭据。

崩溃报告。

SD Card Import 不会自动上传崩溃报告。应用崩溃时，macOS 可能会保存本地报告，你可以自行决定是否分享。

~/Library/Logs/DiagnosticReports/

如果支持人员需要崩溃报告，请使用 macOS“控制台”查找，并在分享前检查内容。SD Card Import 无法浏览系统崩溃报告。

购买与恢复使用权限

14 天内可免费无限次完成导入。之后一次支付 9.99 美元（美国价格）即可终身使用，并支持家人共享。扫描与预览始终免费，各地定价可能不同。试用不会续期，也不会自动扣费；没有订阅。

在 SD Card Import 中选择“设置 > 通用 > 恢复购买”。请使用购买时的 Apple 账户或符合条件的家人共享账户。如果仍无法获得访问权限，请联系支持并提供应用版本和购买窗口显示的内容。

重新打开已关闭的窗口

在 SD Card Import 中选择“窗口”>“显示 SD Card Import”，选择“文件”>“从存储卡导入”（Command-I），或点击程序坞中的应用图标。
