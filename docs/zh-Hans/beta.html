Mac 版 TestFlight

加入 SD Card Import 测试。

在 Mac 上测试 SD Card Import，并分享你的反馈。

通过 TestFlight 加入 获取 Mac 版 TestFlight

TestFlight 会显示你目前可以使用的测试构建版本。可用情况和功能可能与 Mac App Store 版本不同。

如何加入

1

安装 TestFlight。

在用于测试的 Mac 上安装 Apple 的 TestFlight App。

2

接受邀请。

在 Mac 上打开公开测试链接，然后按照 TestFlight 中的步骤安装 SD Card Import。

3

分享反馈。

通过 TestFlight 发送反馈，或通过电子邮件告诉我们 App 版本和遇到的情况。

通过电子邮件发送测试反馈

系统要求

  • 搭载 Apple 芯片或 Intel 处理器的 Mac。
  • macOS 14 或更新版本。
需要帮助？发送邮件至 sd-card-import@jenny.media，或提交 GitHub 问题。
