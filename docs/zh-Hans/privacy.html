隐私政策

最后更新：2026-09-30。本政策适用于 SD Card Import，这是一款从 SD 卡或所选源文件夹复制照片和视频的 macOS 应用。

本地保存的数据

SD Card Import 将设置、文件夹权限、导入历史和重复检测记录保存在你的 Mac 本地。它使用与存储卡检测辅助程序共享的 App Group 容器，也可能通过 macOS UserDefaults 保存偏好设置。

可选的便携导入回执

启用便携导入回执后，应用会在可写源上创建或追加 .sd-import/imported-v1.jsonl。此隐藏台账包含带版本的文件指纹、相对源路径、大小、修改和导入时间戳及校验和，便于另一台 Mac 避免重复导入。它不包含目标路径、用户名或媒体内容。此选项默认关闭；只读源会继续处理而不写入便携历史；台账访问会拒绝通过符号链接重定向到所选源之外。

网络使用

Apple 负责 App Store 下载、更新和 StoreKit 购买。打开网站链接或反馈会使用浏览器或邮件应用。SD Card Import 不会上传您的媒体。

App Store 购买

Apple 处理 SD Card Import 的购买和恢复。应用通过经验证的 StoreKit 交易及权益信息，确定 14 天试用或终身使用权限是否有效。试用期从经验证的交易日期开始计算。我们不会收到付款卡信息。

无自动遥测

SD Card Import 不会自动向维护者发送分析数据、遥测、导入历史、媒体、文件夹列表或崩溃报告。仅在您请求时导出诊断，其中可能包含文件夹名称、路径和错误文本。分享前请检查并隐去私人信息。应用无法浏览系统崩溃报告。

支持请求

通过电子邮件联系支持时，您自行选择经邮件服务提供商发送的消息和附件。公开的 GitHub 问题对所有人可见。请勿在公开问题中附上私人照片、视频、完整存储卡转储、凭据或未经处理的日志。

联系方式

隐私与支持问题请发邮件至 sd-card-import@jenny.media。
