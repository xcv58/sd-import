隐私政策

最后更新：2026-09-10。本政策涵盖 SD Import（直接下载版）和 SD Card Import（App Store 版），它们是在本地将 SD 卡或所选源文件夹中的照片和视频拷贝到目标位置的 macOS 工具。

本地保存的数据

两个版本都在 Mac 本地保存应用设置、文件夹权限、导入历史和用于跳过重复导入的记录。直接下载版使用 ~/Library/Application Support/SD Import/state.sqlite。SD Card Import 使用与存储卡检测辅助程序共享的本地 App Group 容器。两个版本也可能通过 macOS UserDefaults 保存常规偏好设置。

可选的便携导入回执

启用便携导入回执后，应用会在可写源上创建或追加 .sd-import/imported-v1.jsonl。此隐藏台账包含带版本的文件指纹、相对源路径、大小、修改和导入时间戳及校验和，便于另一台 Mac 避免重复导入。它不包含目标路径、用户名或媒体内容。此选项默认关闭；只读源会继续处理而不写入便携历史；台账访问会拒绝通过符号链接重定向到所选源之外。

网络使用

如果已安装的发行版配置了更新检查，直接下载版会使用 Sparkle 连接本仓库托管在 GitHub Release 上的 appcast。SD Card Import 通过 App Store 接收更新，不包含 Sparkle。

App Store 购买

Apple 处理 SD Card Import 的购买和恢复。应用通过 StoreKit 交易及权益信息确定购买权限，并在本地保存购买权限状态和免费导入使用情况。我们不会收到付款卡信息。

无自动遥测

两个版本都不会向维护者发送分析数据、遥测、导入历史、媒体文件、文件夹列表或崩溃报告。诊断导出由你选择，并经过隐私处理。直接下载版可以显示 macOS 崩溃报告文件夹，或导出最新的本地应用崩溃报告。App Store 版无法浏览系统崩溃报告。两个版本都不会自动上传崩溃报告。

支持请求

公开的 GitHub 问题对所有人可见。请勿在公开问题中附上私人照片、视频、完整存储卡转储、凭据或未经隐私处理的日志。

联系方式
