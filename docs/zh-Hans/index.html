一些常见问题

插卡
之前。

需要帮助？
可以导入哪些照片和视频？

SD Card Import 识别常见的 RAW、JPEG 和视频格式。扫描也会显示相机元数据附属文件和不支持的文件，方便你检查卡上的内容。完整流程请参阅指南。

再次导入同一张卡会怎样？

SD Card Import 识别导入历史中记录的文件并跳过重复拷贝。开始前，预览会显示哪些是新文件、哪些已导入。

文件保存在哪里？

保存在你选择的目标文件夹中。照片和视频可以放在一起，也可以使用不同的目标位置，并按拍摄日期整理。拷贝前可检查计划路径。

SD Card Import 会删除卡上的内容吗？

SD Card Import 拷贝媒体时不会自动删除源卡上的原件。导入结束后，可以安全推出受支持的可移动存储卡。

两个版本有什么区别？

此处提供的直接下载版免费，并依据 MIT 许可证开源。可以下载已签名的应用，或查看 GitHub 上的源代码。App Store 版 SD Card Import 可免费完成一次导入，之后一次支付 9.99 美元（美国价格）即可无限次导入，并支持家人共享。扫描和预览始终免费。

开始使用需要什么？

一台运行 macOS 14 或更新版本的 Mac、已挂载的存储卡或源文件夹，以及目标位置的足够空间。从 App Store 安装 SD Card Import 并选择文件夹。安装指南涵盖两个版本。
