SD Card Import · Mac App Store

SD Card Import 支持运行 macOS 14 或更新版本的 Apple 芯片和 Intel Mac。可在 Mac App Store 下载。

可免费成功完成一次导入。之后一次支付 9.99 美元（美国价格）即可解锁无限次完成导入，并支持家人共享。扫描与预览始终免费，各地定价可能不同，无订阅。

通过 App Store 安装 SD Card Import，然后在应用中选择源文件夹和目标文件夹。Apple 负责安装、更新和购买。

SD Import · 免费直接下载

下载 DMG，将应用移到“应用程序”，然后在首次启动时选择导入文件夹。

要求：Apple 芯片 Mac、macOS 14 或更新版本，以及所选照片或视频目标位置的足够可用空间。

下载 Apple 芯片 Mac 版 查看最新 GitHub Release

Gatekeeper 与首次启动。

如果 macOS 提示应用来自互联网，请选择“打开”。如果首次启动被阻止，请打开“系统设置”中的“隐私与安全性”，为 SD Import 选择“仍要打开”。

系统要求

  • Apple 芯片 Mac。
  • macOS 14 或更新版本。
  • SD 卡、读卡器、相机中已挂载的存储卡，或所选源文件夹。
  • 所选照片或视频目标位置有足够可用空间。
