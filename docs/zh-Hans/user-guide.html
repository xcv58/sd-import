使用指南

设置一次目标位置，每次拷贝前预览存储卡，清楚记录 SD Import 已导入的内容。

本指南截图展示直接下载版 SD Import。SD Card Import 是 App Store 版；请参阅获取方式与价格及购买与恢复帮助。

使用 SD Card Import？从 Mac App Store 安装，然后选择源文件夹和目标文件夹。下方流程展示直接下载版 SD Import。

快速开始。

大多数用户只需安装一次、设置一次目标位置，并在每次插卡时检查预览。

1

安装

下载已签名的 DMG，打开后将 SD Import.app 拖入 Applications。

2

设置文件夹

打开“设置”，选择照片和视频目标位置，还可启用自动推出源设备或便携导入回执。便携回执会在可写源上写入隐藏的 .sd-import 台账，让其他 Mac 避免重复导入。

3

导入

插卡并检查预览，拷贝进度完成前保持连接。从便携历史识别的文件会标记为 另一台 Mac；拷贝前会重新检查历史，重建目标计划时 仍然导入 保持启用。完成后可从回执推出源设备。

从存储卡导入。

存储卡挂载时 SD Import 可自动出现，也可以打开应用并选择 从存储卡导入…。

  1. 1

    连接存储卡。

    插入 SD 卡或连接相机读卡器。

  2. 2

    检查扫描结果。

    检查新增、已导入、不支持或存在冲突的文件。

  3. 3

    开始拷贝。

    确认目标位置，保持源设备连接直到导入完成。

  4. 4

    安全推出。

    在回执中选择 弹出来源，或在“设置”中启用自动推出。只有导入无错误时才会自动推出。

安全说明

  • SD Import 拷贝文件，不会抹掉存储卡。
  • 启用便携回执后，SD Import 仅在源上写入隐藏的 .sd-import 台账。已锁定和只读源会继续导入，并显示警告。
  • 已导入文件会在之后跳过。仍然导入 仅适用于从便携历史识别的文件。如果源文件在扫描后改变，SD Import 会要求重新扫描，不会使用过期历史。
  • 如果目标位置已有不同内容的同名文件，SD Import 会添加后缀，保留两个文件。
  • 将应用保留在 Applications 中，以便正确安装更新。

键盘快捷键

  • Command-I：打开导入。
  • Command-1 至 Command-4：导入、历史、设置、诊断。
  • Control-Tab：下一个面板。
  • Command-R：刷新历史。
  • Command-,：设置。

如果导入没有自动开始。

确保已在“设置”中启用 存储卡挂载时提示，手动打开 SD Import，再选择 从存储卡导入…。如果问题持续，请导出诊断并联系支持。
