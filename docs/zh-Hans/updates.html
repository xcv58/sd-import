让应用保持最新。

SD Card Import 通过 App Store 接收更新。打开 App Store 并查看“更新”。

以下说明和下载适用于使用 Sparkle 与 GitHub Releases 的直接下载版 SD Import。获取 App Store 版。

手动检查

  1. 从“应用程序”打开 SD Import。
  2. 选择 SD Import > 检查更新…。
  3. 如果 Sparkle 提示没有可用更新，则应用已是公开更新源中的最新版本。

在 GitHub 上核对

将已安装应用的版本与最新 GitHub Release 比较。公开发行版包含 SD-Import.dmg、SD-Import.zip、appcast.xml 和发行说明。

最新 GitHub Release

如果更新看起来不对。

请先使用最新公开发行版；如果导入仍不符合预期，再分享诊断。

再次检查更新，将已安装版本与最新 GitHub Release 比较，必要时重新安装最新 DMG，然后联系支持并提供预览摘要和诊断导出。
