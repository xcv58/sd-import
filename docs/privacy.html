Privacy Policy

Last updated: 2026-09-10. This policy covers SD Import (direct download) and SD Card Import (App Store edition), local macOS utilities for copying photos and videos from SD cards or selected source folders.

Data stored locally

Both editions store app settings, folder permissions, import history, and records used to skip duplicate imports locally on your Mac. The direct edition uses ~/Library/Application Support/SD Import/state.sqlite. SD Card Import uses a local App Group container shared with its card-detection helper. Both may also store ordinary preferences through macOS UserDefaults.

Optional portable import receipts

If you enable portable import receipts, the app creates or appends .sd-import/imported-v1.jsonl on writable sources. The hidden ledger contains versioned file fingerprints, relative source paths, sizes, modification and import timestamps, and validation checksums so another Mac can avoid duplicate imports. It does not contain destination paths, usernames, or media contents. The option is disabled by default, read-only sources continue without writing portable history, and ledger access refuses symbolic-link redirection outside the selected source.

Network use

The direct edition uses Sparkle for update checks when configured in the installed release. These checks contact the GitHub Release-hosted appcast for this repository. SD Card Import receives updates through the App Store and does not include Sparkle.

App Store purchases

Apple processes purchases and restores for SD Card Import. The app uses StoreKit transaction and entitlement information to determine purchase access. It stores purchase-access state and free-import usage locally. We do not receive payment card details.

No automatic telemetry

Neither edition sends analytics, telemetry, import history, media files, folder listings, or crash reports to the maintainer. Diagnostics export is opt-in and redacted. The direct edition can reveal the macOS crash-report folder or export the latest local app crash report. The App Store edition cannot browse system crash reports. Neither edition uploads crash reports automatically.

Support requests

Public GitHub issues are visible to everyone. Do not attach private photos, videos, full card dumps, credentials, or unredacted logs to public issues.
