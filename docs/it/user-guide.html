Guida all’uso

Imposta le destinazioni una volta, controlla ogni scheda prima di copiare e conserva una cronologia chiara di ciò che SD Import ha già importato.

Le istantanee di questa guida mostrano SD Import, l’edizione diretta. SD Card Import è l’edizione App Store: consulta disponibilità e prezzi e l’aiuto per acquisti e ripristino.

Usi SD Card Import? Installalo dal Mac App Store e scegli le cartelle sorgente e di destinazione. I passaggi seguenti mostrano SD Import, l’edizione diretta.

Avvio rapido.

In genere basta installare l’app e impostare le destinazioni una volta, poi controllare l’anteprima quando si inserisce una scheda.

1

Installa

Scarica il DMG firmato, aprilo e trascina SD Import.app in Applications.

2

Imposta le cartelle

Apri Impostazioni, scegli le destinazioni di foto e video e, se vuoi, attiva l’espulsione automatica o le ricevute d’importazione portatili. Queste scrivono un registro nascosto .sd-import sulle sorgenti scrivibili per evitare duplicati su altri Mac.

3

Importa

Inserisci la scheda, controlla l’anteprima e lasciala collegata fino al termine della copia. I file riconosciuti dalla cronologia portatile sono etichettati Altro Mac; la cronologia viene ricontrollata prima della copia e Importa comunque resta attivo mentre si ricostruisce il piano di destinazione. Al termine, espelli la sorgente dal riepilogo.

Importa da una scheda.

SD Import può apparire automaticamente quando viene montata una scheda, oppure puoi aprire l’app e scegliere Importa dalla scheda….

  1. 1

    Collega una scheda.

    Inserisci una scheda SD o collega un lettore di schede per fotocamera.

  2. 2

    Controlla la scansione.

    Verifica i file nuovi, già importati, non supportati o in conflitto.

  3. 3

    Avvia la copia.

    Conferma le destinazioni e lascia collegata la sorgente fino al termine dell’importazione.

  4. 4

    Espelli in sicurezza.

    Scegli Espelli sorgente nel riepilogo o attiva l’espulsione automatica in Impostazioni. Avviene solo dopo un’importazione senza errori.

Precauzioni

  • SD Import copia i file; non cancella la scheda.
  • Con le ricevute portatili attive, SD Import scrive sulla sorgente solo il registro nascosto .sd-import. Le sorgenti bloccate o di sola lettura continuano a funzionare con un avviso.
  • I file già importati vengono saltati nelle esecuzioni successive. Importa comunque è disponibile solo per quelli riconosciuti dalla cronologia portatile. Se un file cambia dopo la scansione, SD Import richiede una nuova scansione anziché usare dati obsoleti.
  • Se esiste già un file diverso nella destinazione, SD Import conserva entrambi aggiungendo un suffisso.
  • Lascia l’app in Applications per consentire l’installazione corretta degli aggiornamenti.

Scorciatoie da tastiera

  • Command-I: apri Importa.
  • Da Command-1 a Command-4: Importa, Cronologia, Impostazioni, Diagnostica.
  • Control-Tab: pannello successivo.
  • Command-R: aggiorna Cronologia.
  • Command-,: Impostazioni.

Se l’importazione non parte automaticamente.

Verifica che Avvisa al montaggio di una scheda sia attivo in Impostazioni, apri SD Import manualmente e scegli Importa dalla scheda…. Se il problema persiste, esporta la diagnostica e contatta il supporto.
