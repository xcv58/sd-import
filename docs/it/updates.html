Mantieni aggiornata la tua app.

SD Card Import riceve aggiornamenti dall’App Store. Apri l’App Store e controlla Aggiornamenti.

Le istruzioni e i download seguenti riguardano SD Import, l’edizione diretta che usa Sparkle e GitHub Releases. Ottieni l’edizione App Store.

Controlla manualmente

  1. Apri SD Import da Applicazioni.
  2. Scegli SD Import > Cerca aggiornamenti….
  3. Se Sparkle non mostra aggiornamenti disponibili, l’app è aggiornata rispetto al canale pubblico.

Verifica su GitHub

Confronta la versione installata con l’ultima release GitHub. Le versioni pubbliche includono SD-Import.dmg, SD-Import.zip, appcast.xml e note di rilascio.

Ultima release GitHub

Se un aggiornamento sembra errato.

Usa prima l’ultima versione pubblica, poi condividi la diagnostica se le importazioni continuano a non funzionare come previsto.

Cerca di nuovo gli aggiornamenti, confronta la tua versione con l’ultima release GitHub, reinstalla il DMG più recente se necessario e contatta il supporto con il riepilogo dell’anteprima e la diagnostica esportata.
