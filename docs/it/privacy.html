Informativa sulla privacy

Ultimo aggiornamento: 2026-09-10. Questa informativa copre SD Import (download diretto) e SD Card Import (edizione App Store), utilità locali di macOS per copiare foto e video da schede SD o cartelle sorgente selezionate.

Dati salvati localmente

Entrambe le edizioni salvano sul Mac impostazioni, permessi delle cartelle, cronologia delle importazioni e registri per evitare duplicati. L’edizione diretta usa ~/Library/Application Support/SD Import/state.sqlite. SD Card Import usa un contenitore locale App Group condiviso con l’assistente di rilevamento delle schede. Entrambe possono salvare preferenze comuni tramite UserDefaults di macOS.

Ricevute d’importazione portatili facoltative

Se le attivi, l’app crea o aggiorna .sd-import/imported-v1.jsonl sulle sorgenti scrivibili. Il registro nascosto contiene impronte dei file con versione, percorsi sorgente relativi, dimensioni, date di modifica e importazione e checksum di verifica per evitare duplicati su un altro Mac. Non contiene percorsi di destinazione, nomi utente o contenuti multimediali. L’opzione è disattivata per impostazione predefinita; le sorgenti di sola lettura proseguono senza scrivere la cronologia portatile e l’accesso al registro rifiuta reindirizzamenti tramite collegamenti simbolici fuori dalla sorgente selezionata.

Uso della rete

L’edizione diretta usa Sparkle per cercare aggiornamenti quando previsto dalla versione installata. Le richieste contattano l’appcast di questo repository ospitato su GitHub Releases. SD Card Import riceve aggiornamenti dall’App Store e non include Sparkle.

Acquisti sull’App Store

Apple gestisce acquisti e ripristini per SD Card Import. L’app usa le informazioni sulle transazioni e sui diritti StoreKit per determinare l’accesso acquistato. Salva localmente tale stato e l’uso dell’importazione gratuita. Non riceviamo dati delle carte di pagamento.

Nessuna telemetria automatica

Nessuna edizione invia al manutentore analisi, telemetria, cronologia, contenuti multimediali, elenchi di cartelle o resoconti di crash. L’esportazione della diagnostica è facoltativa e rimuove i dati privati. L’edizione diretta può mostrare la cartella dei resoconti di macOS o esportare l’ultimo resoconto locale dell’app. L’edizione App Store non può esplorare i resoconti di sistema. Nessuna edizione li carica automaticamente.

Richieste di supporto

Le segnalazioni pubbliche su GitHub sono visibili a tutti. Non allegare foto o video privati, copie integrali di schede, credenziali o log senza rimozione dei dati privati.
