Il supporto parte dall’anteprima.

Supporto per SD Import (download diretto) e SD Card Import (edizione App Store). Versione dell’app e di macOS, stato della destinazione e riepilogo del lavoro aiutano a diagnosticare la maggior parte dei problemi.

Contatti

Supporto via email: i@xcv58.com

Bug pubblici e richieste di funzionalità: GitHub Issues

Segnalazioni di sicurezza: segui SECURITY.md e non aprire segnalazioni pubbliche per sospette vulnerabilità.

Contatta l’assistenza via email Apri una segnalazione pubblica

Cosa includere

  • Nome, versione e build dell’app: SD Import o SD Card Import.
  • Versione di macOS e modello di Mac.
  • Marca della fotocamera o scheda, file system e tipo di lettore.
  • Se l’importazione è partita automaticamente o manualmente.
  • Cosa mostrava l’anteprima e cosa è successo dopo.

Esporta la diagnostica.

L’esportazione è facoltativa e rimuove i dati privati. Esclude contenuti multimediali, nomi dei file e percorsi completi di sorgente e destinazione.

1

Apri Diagnostica

In entrambe le edizioni, scegli Diagnostica nella barra laterale.

2

Esporta

Scegli Copia diagnostica o Esporta diagnostica. Controlla il file prima di condividerlo.

3

Scegli gli allegati

Condividi solo il necessario. Non allegare contenuti privati, copie integrali di schede o credenziali.

Resoconti di crash.

Nessuna edizione carica automaticamente resoconti di crash. In caso di arresto anomalo, macOS può salvare un resoconto locale che puoi scegliere di condividere.

~/Library/Logs/DiagnosticReports/

Nell’edizione diretta usa Diagnostica, Mostra resoconti di crash o Esporta ultimo resoconto. L’edizione App Store non può esplorare i resoconti di sistema; usa Console di macOS se il supporto ne richiede uno. Controllalo prima di condividerlo.

Acquisti e ripristino dell’accesso

SD Card Import include un’importazione completata gratis. L’acquisto SD Import Unlimited sblocca importazioni completate illimitate con “In famiglia”. Scansione e anteprima restano gratuite. SD Import, l’edizione diretta, è gratuita e senza acquisti in-app.

In SD Card Import, apri Impostazioni > Acquisto e scegli Ripristina acquisti. Usa l’Apple Account dell’acquisto o un account idoneo a “In famiglia”. Se l’accesso manca ancora, contatta il supporto con la versione dell’app e ciò che mostra la schermata d’acquisto.

Riaprire una finestra chiusa

In SD Card Import, scegli Finestra > Mostra SD Card Import, File > Importa da scheda (Comando-I), oppure fai clic sull’icona dell’app nel Dock.
