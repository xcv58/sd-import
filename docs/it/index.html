Serve una mano?
Quali foto e video posso importare?

SD Card Import riconosce i formati RAW, JPEG e video più comuni. La scansione mostra anche i file accessori dei metadati e quelli non supportati, per controllare il contenuto della scheda. Consulta la guida per il flusso completo.

Cosa succede se importo di nuovo la stessa scheda?

SD Card Import riconosce i file registrati nella cronologia ed evita copie ripetute. Prima di iniziare, il controllo mostra le novità e i file già importati.

Dove finiscono i miei file?

Nelle cartelle di destinazione scelte. Puoi tenere foto e video insieme, usare destinazioni separate e organizzare per data di scatto. Controlla i percorsi previsti prima di copiare.

SD Card Import cancella qualcosa dalla scheda?

SD Card Import copia i contenuti senza eliminare automaticamente gli originali dalla scheda. Al termine puoi espellere in sicurezza una scheda rimovibile supportata.

Qual è la differenza tra le edizioni?

Il download diretto qui indicato è gratuito e open source con licenza MIT. Puoi scaricare l’app firmata o esplorare il codice su GitHub. SD Card Import, l’edizione App Store, include un’importazione completata gratis; poi un acquisto unico di 9,99 USD negli USA sblocca importazioni illimitate con “In famiglia”. Scansione e anteprima restano gratuite.

Cosa serve per iniziare?

Un Mac con macOS 14 o successivo, una scheda montata o una cartella sorgente e spazio sufficiente a destinazione. Installa SD Card Import dall’App Store e scegli le cartelle. La guida all’installazione copre entrambe le edizioni.
