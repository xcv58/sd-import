Keep your app up to date.

SD Card Import receives updates through the App Store. Open the App Store and check Updates.

The instructions and downloads below are for SD Import, the direct edition, which uses Sparkle and GitHub Releases. Get the App Store edition.

Check manually

  1. Open SD Import from Applications.
  2. Choose SD Import > Check for Updates....
  3. If Sparkle says no update is available, the app is current for the public feed.

Verify on GitHub

Compare the installed app version with the latest GitHub Release. Public releases include SD-Import.dmg, SD-Import.zip, appcast.xml, and release notes.

Latest GitHub Release

If an update looks wrong.

Use the latest public release first, then share diagnostics if imports still do not behave as expected.

Check for updates again, compare your installed version with the latest GitHub Release, reinstall the latest DMG if needed, then contact support with the preview summary and diagnostics export.
