User Guide

Set destinations once, preview each card before copying, and keep a clear record of what SD Import already imported.

The screenshots in this guide show SD Import, the direct edition. SD Card Import is the App Store edition; see availability and pricing and purchase and restore help.

Using SD Card Import? Install from the Mac App Store, then choose your source and destination folders. The walkthrough below shows the direct edition, SD Import.

Quick start.

Most users only need to install once, set destinations once, and review the preview each time a card is inserted.

1

Install

Download the signed DMG, open it, and drag SD Import.app into Applications.

2

Set folders

Open Settings, choose photo and video destinations, and optionally enable automatic source ejection or portable import receipts. Portable receipts write a hidden .sd-import ledger on writable sources so other Macs can avoid duplicate imports.

3

Import

Insert a card, review the preview, then keep the card connected until copy progress finishes. Files recognized from portable history are labeled Other Mac; history is rechecked before copying, and Import Anyway remains active while the destination plan is rebuilt. Eject the source from the receipt when you are done.

Import from a card.

SD Import can appear automatically when a card mounts, or you can open the app and choose Import From Card....

  1. 1

    Connect a card.

    Insert an SD card or connect a camera card reader.

  2. 2

    Review the scan.

    Check what is new, already imported, unsupported, or conflicting.

  3. 3

    Start the copy.

    Confirm the destinations and leave the source connected until the import completes.

  4. 4

    Eject safely.

    Choose Eject Source on the receipt, or enable automatic ejection in Settings. Automatic ejection runs only after an error-free import.

Safety notes

  • SD Import copies files; it does not erase the card.
  • When portable receipts are enabled, SD Import writes only its hidden .sd-import ledger on the source. Locked and read-only sources continue with a warning.
  • Files already imported are skipped on future runs. Import Anyway is available only for files recognized from portable history. If a source file changes after scanning, SD Import requires a rescan instead of applying stale history.
  • If a destination file already exists but is different, SD Import keeps both files by adding a suffix.
  • Leave the app in Applications so updates can install correctly.

Keyboard shortcuts

  • Command-I: open Import.
  • Command-1 through Command-4: Import, History, Settings, Diagnostics.
  • Control-Tab: next panel.
  • Command-R: refresh History.
  • Command-,: Settings.

If import does not start automatically.

Make sure Prompt on card mount is enabled in Settings, open SD Import manually, then choose Import From Card.... For persistent issues, export diagnostics and contact support.
