Support starts with the preview.

Support for SD Import (direct download) and SD Card Import (App Store edition). Most import problems are easier to diagnose with the app version, macOS version, destination status, and the selected job summary.

Contact

Email support: i@xcv58.com

Public bugs and feature requests: GitHub Issues

Security reports: follow SECURITY.md and do not open a public issue for suspected vulnerabilities.

Email support Open a public issue

What to include

  • App name, version, and build: SD Import or SD Card Import.
  • macOS version and Mac model.
  • Camera/card brand, filesystem, and reader type.
  • Whether the import was automatic or manually started.
  • What the preview showed and what happened after import.

Export diagnostics.

Diagnostics export is opt-in and redacted. It excludes media files, filenames, and full source/destination paths.

1

Open Diagnostics

In either edition, choose the Diagnostics section from the sidebar.

2

Export

Choose Copy Diagnostics or Export Diagnostics. Review the file before sharing it.

3

Attach selectively

Share only what is needed. Do not attach private media, full card dumps, or credentials.

Crash reports.

Neither edition uploads crash reports automatically. If the app crashes, macOS may store a local crash report that you can choose to share.

~/Library/Logs/DiagnosticReports/

In the direct edition, use Diagnostics, Reveal Crash Reports or Export Latest Crash Report. The App Store edition cannot browse system crash reports; use macOS Console to locate a report if support requests one. Review it before sharing.

Purchases and restoring access

SD Card Import includes one completed import free. The SD Import Unlimited purchase unlocks unlimited completed imports with Family Sharing. Scanning and previewing remain free. The direct edition, SD Import, is free and has no in-app purchase.

In SD Card Import, open Settings > Purchase and choose Restore Purchases. Use the Apple Account that made the purchase, or an eligible Family Sharing account. If access is still missing, contact support with the app version and what the purchase sheet shows.

Reopen a closed window

In SD Card Import, choose Window > Show SD Card Import, choose File > Import From Card (Command-I), or click the app’s Dock icon.
